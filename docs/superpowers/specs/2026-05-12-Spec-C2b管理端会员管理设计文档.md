## 1. 概述与范围

### 1.1 目标

为管理端补齐 `/member` 模块的完整后台运营能力——会员等级配置、付费套餐配置、会员用户管理（含积分/等级/套餐三类高敏写操作）、统计仪表盘、积分流水追溯。本 spec 与 Spec-C1（system 4 页）+ Spec-C2a（user/feedback）共同形成"管理端三大业务模块"完整闭环。

### 1.2 不在范围（明确排除）

| 排除项 | 原因/归属 |
|---|---|
| 等级 / 套餐的 CRUD（增/删） | 后端仅提供 update（业务约定：等级/套餐由开发预置） |
| C 端会员中心（个人页、签到、积分商城） | 已实装 / 独立产品 spec |
| 会员到期推送 / 营销活动 | 独立 spec（涉及消息中心） |
| 第三方支付集成 | 独立 spec |
| 引入图表库（ECharts / Recharts / @ant-design/plots） | brainstorming Q8=C：不引入 |
| 后端接口改动 | **C2b 是纯前端 spec**（与 C1 同性质） |

### 1.3 前后端总览

#### 前端（admin 端）

| 路由 | 页面 | 主要权限码 |
|---|---|---|
| `/member/stats` | 会员统计仪表盘（4 卡片 + 等级分布 Progress） | `member:stats:view` |
| `/member/config` | 配置中心（Tab：等级 / 套餐） | `member:level:list` + `member:plan:list` |
| `/member/users` | 会员用户（Tab：用户列表 / 积分流水） | `member:user:list` + `member:points:log:view` |

#### 后端：✅ 零改动

11 个接口已在 master 实装（007_add_member_module.sql 已迁移），权限码完整。本 spec 仅消费现有契约。

### 1.4 与 Spec-C1 / C2a 的关系

| 维度 | C1 | C2a | C2b |
|---|---|---|---|
| 性质 | 纯前端 | 前后端联合 | **纯前端**（与 C1 同） |
| 范围 | 系统管理 4 页 | 用户 + 反馈 2 模块 | 会员 1 模块（3 页 + Tab） |
| 测试目标 | 10 case | 22 case | ≥ 13 case |
| 业务复杂度 | 中（RBAC 树形赋权） | 中（自身保护 + 状态机） | **高**（高敏写操作 + JSON 编辑）|

### 2.2 接口 1：等级列表 `GET /api/admin/member/levels`

#### 响应

```json
{
  "code": 200,
  "data": [
    {
      "id": 1, "name": "免费用户", "code": "free", "level": 0,
      "icon": "https://...png", "color": "#999",
      "upgradePoints": 0, "upgradeGrowth": 0, "upgradeConsume": "0.00",
      "benefits": { "discount": 1, "freeTools": [] },
      "description": "...", "sort": 0, "status": 1,
      "createdAt": "...", "updatedAt": "..."
    }
  ]
}
```

⚠️ **关键约定**：直接返回数组（**非分页**）；levels 数据量小（业务约定 3-6 条）。

### 2.3 接口 2：更新等级 `PUT /api/admin/member/levels/:id`

#### 请求

允许字段（部分更新）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 50 字符内 |
| `icon` | string | 500 字符 URL |
| `color` | string | 20 字符（hex） |
| `upgradePoints` | number | 升级所需积分（>=0） |
| `upgradeGrowth` | number | 升级所需成长值（>=0） |
| `upgradeConsume` | number | 升级所需消费金额（DECIMAL） |
| `benefits` | object/JSON | 权益配置 |
| `description` | string | 500 字符 |
| `sort` | number | 排序 |
| `status` | 0/1 | 启停 |

⚠️ **不允许改**：`code`、`level`（业务约定），前端 UI 应 disabled。

#### 响应

```json
{ "code": 200, "data": { ...更新后完整对象 }, "message": "更新成功" }
```

#### 审计

后端已记：module=`member`, action=`update_level`, beforeData/afterData。前端无需重复。

### 2.5 接口 4：更新套餐 `PUT /api/admin/member/plans/:id`

### 2.8 接口 7：调整积分 `POST /api/admin/member/users/:id/adjust-points`

#### 请求

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `points` | number | ✅ | 正数加，负数扣 |
| `growthDelta` | number | 否 | 同步调整成长值（默认 0） |
| `remark` | string | ✅ | 后端 service.adjustPoints 强制非空（`!remark` 抛 400） |

#### 响应

```json
{ "code": 200, "data": { ...调整后的 UserMember 对象 }, "message": "调整成功" }
```

⚠️ **关键约束**：
1. `remark` 必填（前端 Form 校验 + 后端兜底）
2. 扣减时如果当前 points 不足，后端 service.addPoints 会抛错（看 service 代码确认）
3. 审计 description: "调整用户 #N 积分 +100（双 11 补偿）"

### 2.9 接口 8：调整等级 `PUT /api/admin/member/users/:id/level`

#### 请求

```json
{ "levelId": 3 }
```

#### 响应

```json
{ "code": 200, "data": { ...UserMember 含新 level }, "message": "等级调整成功" }
```

注：等级调整 levelId 不存在时后端抛 404；UI 应只展示已存在的等级。

### 2.10 接口 9：开通套餐 `POST /api/admin/member/users/:id/activate-plan`

#### 请求

```json
{ "planCode": "monthly" }
```

⚠️ 注意是 **`planCode`**（字符串）而不是 planId！前端从套餐列表中取 code 字段。

#### 响应

```json
{ "code": 200, "data": { ...UserMember 含 paidStartAt/paidExpireAt }, "message": "开通成功" }
```

后端会自动计算 paidExpireAt（基于 plan.durationDays）+ 赠送 giftPoints/giftGrowth + 写 audit。

### 2.11 接口 10：会员统计 `GET /api/admin/member/stats`

#### 响应

```json
{
  "code": 200,
  "data": {
    "totalMembers": 1000,
    "paidMembers": 200,
    "paidRate": 0.2,
    "levelDistribution": { "free": 800, "silver": 150, "gold": 40, "diamond": 10 },
    "todayNewMembers": 23
  }
}
```

⚠️ paidRate 是浮点数（0.0-1.0），UI 显示需 `* 100` + 加 `%`。

### 2.12 接口 11：积分流水 `GET /api/admin/member/points-logs`

#### 请求

| 字段 | 类型 | 说明 |
|---|---|---|
| `page` `pageSize` | number | 分页 |
| `userId` | number | 单用户筛选 |
| `type` | 0/1 | 0=支出 1=收入（按 model 推测，T1 联调验证） |
| `source` | string | sign / adjust / activate / consume / ... |
| `startDate` `endDate` | string | createdAt 范围 |

#### 响应

走 `paginated`：`data: { list, total, page, pageSize, totalPages }`。

list 元素：

```json
{
  "id": 1, "userId": 5, "type": 1, "source": "adjust",
  "points": 100, "balance": 2500, "growthDelta": 0,
  "bizType": null, "bizId": null,
  "remark": "双 11 补偿", "expireAt": null,
  "createdAt": "..."
```

⚠️ 是否含 user.username 待 T1 验证。如未 include，可在前端用 `userId` 显示后跳详情。

### 5.5 BenefitsField（JSON 编辑器）

```tsx
// 自定义 Form.Item，受控组件
interface Props {
  value?: object;
  onChange?: (v: object) => void;
}

const BenefitsField: React.FC<Props> = ({ value, onChange }) => {
  const [text, setText] = useState(JSON.stringify(value ?? {}, null, 2));
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    setText(JSON.stringify(value ?? {}, null, 2));
  }, [value]);

  const handleChange = (e: React.ChangeEvent<HTMLTextAreaElement>) => {
    const v = e.target.value;
    setText(v);
    try {
      const parsed = v.trim() ? JSON.parse(v) : {};
      setError(null);
      onChange?.(parsed);
    } catch (err: any) {
      setError(err.message);
    }
  };

  return (
    <div>
      <Input.TextArea
        rows={6}
        value={text}
        onChange={handleChange}
        style={{ fontFamily: 'Consolas, monospace', fontSize: 13 }}
        placeholder='{"discount": 0.8, "freeTools": ["calc","note"]}'
      />
      {error && <div style={{ color: '#ff4d4f', marginTop: 4 }}>JSON 格式错误：{error}</div>}
    </div>
  );
};
```

外层 Form.Item 加 validator：

```tsx
<Form.Item
  label="权益配置（JSON）"
  name="benefits"
  rules={[{
    validator: (_, v) => {
      if (typeof v !== 'object' || v === null) return Promise.reject('benefits 必须是 JSON 对象');
      return Promise.resolve();
    },
  }]}
>
  <BenefitsField />
</Form.Item>
```

```typescript
/** 格式化货币（DECIMAL string → ¥xxx.xx） */
export function formatCurrency(v: string | number | undefined | null): string {
  if (v == null) return '-';
  const n = typeof v === 'string' ? parseFloat(v) : v;
  if (isNaN(n)) return '-';
  return `¥${n.toFixed(2)}`;
}

/** 格式化时长 */
export function formatDuration(days: number | undefined): string {
  if (days == null || days === 0) return '永久';
  if (days >= 365 && days % 365 === 0) return `${days / 365} 年`;
  if (days >= 30 && days % 30 === 0) return `${days / 30} 月`;
  return `${days} 天`;
}

/** 等级颜色降级（如 level.color 缺失时用名称首字符 hash） */
```
