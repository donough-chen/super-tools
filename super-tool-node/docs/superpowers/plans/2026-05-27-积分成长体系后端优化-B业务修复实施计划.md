## Task B1: member.refundPoints 原批次回写（含 overflow 兜底）

**Files:**

- Modify: `app/service/member.ts:refundPoints`
- Create: `test/service/member.refundPoints.test.ts`

**说明：** spec §2.7-#21。当前 `refundPoints` 只回写"原批次" `pointsRemaining`，且原批次余额已被消费扣完时，剩余退款仍试图扣会员余额（在 UNSIGNED 时代会出问题）。本 task 重写为：

1. **原批次回写**：`recoverHere = min(R, B.alreadyConsumed)`，其中 `B.alreadyConsumed = B.points - B.pointsRemaining`
2. **overflow 兜底**（Q-B=a 决策）：`overflow = R - recoverHere ≥ 0`，超出原批次容量的部分**不报错**，直接计入会员余额（极少见但保留兜底）
3. **expiresAt 继承**（Q-C=a 决策）：refund 流水的 `expiresAt` = 原批次 `expiresAt`；若原批次已过期，refund 流水的 pointsRemaining 增加但 status=2，**FIFO 永不命中**（业务原则：积分有效期不可延长）
4. **会员余额加全 R**：`new M.points = M.points + R`（已 SIGNED，可负 → 可正；不再钳零）
5. **triggerEvent 语义化**（Q-D=c 决策）：refund 流水 `triggerEvent='mall_refund'`，原批次 id 放 `metadata.refundFromLogId`

**风险高，必须有 feature flag**：`mall.refund.reverse_fifo`（沿用历史命名，含义为"新版退款逻辑"），默认 false（保持原逻辑），灰度后再开。flag 由 Redis 60s 缓存（Q1=b 决策）。

> **核心账本公式（B1 灵魂）：**
>
> ```
> recoverHere      = min(R, B.points - B.pointsRemaining)
> new B.pR         = B.pR + recoverHere   // 上限 = B.points
> overflow         = R - recoverHere      // ≥ 0
> new M.points     = M.points + R         // SIGNED，可负
> refund 流水:
>   points          = R
>   pointsRemaining = R
>   balance         = M.points + R
>   expiresAt       = B.expiresAt         // 继承
>   triggerEvent    = 'mall_refund'
>   metadata.refundFromLogId = B.id
> ```

### 📊 6 个边界 case 账本（review 后锁定）

> **统一前置**：M.points=100，B = 单批 60 分（B.points=60, B.pR=60, B.expiresAt=2027-01-01）

|  #  | 场景                         |   前置消费    | M (消费后) | B.pR (消费后) |   退款 R   | recoverHere | overflow | new B.pR | new M | refund 流水 (points / balance / expiresAt / triggerEvent) |

|  4  | B 未耗尽时部分退款           |      30       |     70     |      30       |     20     |     20      |    0     |    50    |  90   | 20 / 90 / 2027-01-01 / mall_refund                        |

```typescript
import { app } from 'egg-mock/bootstrap';
import { Op } from 'sequelize';

/**
 * B1 账本契约（review 锁定的 6 个 case）
 *  统一前置：M=100，B=单批 60 分（B.points=60, B.pR=60, B.expiresAt=2027-01-01）
 *  公式：recoverHere = min(R, B.points - B.pR), overflow = R - recoverHere, new M = M + R

describe('service/member.refundPoints (原批次回写 + overflow 兜底)', () => {
	let userId: number;
	let originalLogId: number;

	// 工具：准备一个用户 + 一笔 60 分入账
	async function setupBatch(initialMemberPoints = 100, batchPoints = 60) {
		const u: any = await (app.model as any).User.create({
			phone: `13800000${Date.now() % 100000}`,
			password: 'x',
		});
		userId = u.id;
		await (app.model as any).UserMember.create({
			userId,
			levelId: 1,
			points: initialMemberPoints,
			growthValue: 0,
		});
		const b: any = await (app.model as any).PointsLog.create({
			userId,
			type: 1,
			orderType: 'earn',
			triggerEvent: 'first_consume',
			points: batchPoints,
			pointsRemaining: batchPoints,
			balance: initialMemberPoints,
			growthDelta: 0,
			expireAt: new Date('2027-01-01'),
			status: 1,
		});
		originalLogId = b.id;
	}

	async function getMemberAndBatch() {
		const m: any = await (app.model as any).UserMember.findOne({
			where: { userId },
		});
		const b: any = await (app.model as any).PointsLog.findByPk(originalLogId);
		return { m, b };
	}

	beforeEach(async () => {
		// 开启新版逻辑（feature flag = true）
		await (app.model as any).query(
			`INSERT INTO system_configs (\`group\`,\`key\`,value) VALUES ('mall','refund.reverse_fifo','true') ON DUPLICATE KEY UPDATE value='true'`,
		);
		// 清 Redis 缓存确保 flag 立即生效
		try {
			await (app as any).redis?.del('feature:refund_reverse_fifo');
		} catch {}
	});

	afterEach(async () => {
		await (app.model as any).PointsLog.destroy({
			where: { userId },
			force: true,
		});
		await (app.model as any).UserMember.destroy({
			where: { userId },
			force: true,
		});
	});

	// ===================== Case 1: 完整退款 =====================
	it('Case 1: 完整退款 60 → B.pR=60, M=100', async () => {
		await setupBatch(100, 60);
		const ctx = app.mockContext();
		// 消费 60
		await (ctx.service as any).member.consumePoints(
			userId,
			60,
			'mall_exchange',
			'mall',
			'1',
		);
		// 退 60
		const r = await (ctx.service as any).member.refundPoints(
			userId,
			originalLogId,
			60,
		);
		const { m, b } = await getMemberAndBatch();
		expect(b.pointsRemaining).toBe(60);
		expect(m.points).toBe(100);
		expect(r.balance).toBe(100);
		// 流水校验
		const refundLog: any = await (app.model as any).PointsLog.findByPk(r.logId);
		expect(refundLog.points).toBe(60);
		expect(refundLog.balance).toBe(100);
		expect(refundLog.triggerEvent).toBe('mall_refund');
		expect(refundLog.pointsRemaining).toBe(60);
		expect(refundLog.metadata?.refundFromLogId).toBe(originalLogId);
	});

	// ===================== Case 2: 部分退款，B 未满 =====================
	it('Case 2: 部分退款 30 → B.pR=30, M=70', async () => {
		await setupBatch(100, 60);
		const ctx = app.mockContext();
		await (ctx.service as any).member.consumePoints(
			userId,
			60,
			'mall_exchange',
			'mall',
			'2',
		);
		const r = await (ctx.service as any).member.refundPoints(
			userId,
			originalLogId,
			30,
		);
		const { m, b } = await getMemberAndBatch();
		expect(b.pointsRemaining).toBe(30);
		expect(m.points).toBe(70);
		expect(r.balance).toBe(70);
	});

	// ===================== Case 3: B 已过期 =====================
	it('Case 3: 原批次已过期，仍可回写 → B.pR=60 (status=2), M=100', async () => {
		await setupBatch(100, 60);
		const ctx = app.mockContext();

			userId,
			60,
			'mall_exchange',
			'mall',
			'3',
		);
		// 强制把原批次过期
		await (app.model as any).PointsLog.update(
			{ status: 2, expireAt: new Date('2025-01-01') },
			{ where: { id: originalLogId } },
		);
		const r = await (ctx.service as any).member.refundPoints(
			userId,
			originalLogId,
			60,
		);
		const { m, b } = await getMemberAndBatch();
		expect(b.pointsRemaining).toBe(60);
		expect(b.status).toBe(2); // 仍过期，FIFO 跳过（不复活）
		expect(m.points).toBe(100); // 余额仍加 R
		// refund 流水的 expiresAt 继承
		const refundLog: any = await (app.model as any).PointsLog.findByPk(r.logId);
		expect(new Date(refundLog.expireAt).getTime()).toBeLessThan(Date.now()); // 立即过期
	});

	// ===================== Case 4: B 未耗尽时部分退款 =====================
	it('Case 4: B 未耗尽部分退款 → B.pR=50, M=90', async () => {
		await setupBatch(100, 60);
		const ctx = app.mockContext();
		await (ctx.service as any).member.consumePoints(
			userId,
			30,
			'mall_exchange',
			'mall',
			'4',
		);
		// 此时 M=70, B.pR=30
		const r = await (ctx.service as any).member.refundPoints(
			userId,
			originalLogId,
			20,
		);
		const { m, b } = await getMemberAndBatch();
		expect(b.pointsRemaining).toBe(50);
		expect(m.points).toBe(90);
		expect(r.balance).toBe(90);
	});

	it('Case 5: 退 80 > B 容量 60 → B.pR=60 (满), M=120, overflow=20', async () => {
		await setupBatch(100, 60);
		const ctx = app.mockContext();
		await (ctx.service as any).member.consumePoints(
			userId,
			60,
			'mall_exchange',
			'mall',
			'5',
		);
		const r = await (ctx.service as any).member.refundPoints(
			userId,
			originalLogId,
			80,
		);
		const { m, b } = await getMemberAndBatch();
		expect(b.pointsRemaining).toBe(60); // 不超过 B.points
		expect(m.points).toBe(120); // M 加全 R=80
		expect(r.balance).toBe(120);
		const refundLog: any = await (app.model as any).PointsLog.findByPk(r.logId);
		expect(refundLog.points).toBe(80);
		expect(refundLog.metadata?.overflow).toBe(20);
		expect(refundLog.metadata?.recoverHere).toBe(60);
	});

	// ===================== Case 6: 跨批次场景（仅退原批次 B1） =====================
	it('Case 6: 跨批次 B1 完全消费 + B2 部分消费，退 B1 60 → B1.pR=60, B2 不动, M=70', async () => {
		const u: any = await (app.model as any).User.create({
			phone: `13800001${Date.now() % 100000}`,

			userId,

			points: 100,
			growthValue: 0,
		});

			userId,
			type: 1,

			points: 60,
			pointsRemaining: 60,
			balance: 60,
			growthDelta: 0,
			expireAt: new Date('2027-01-01'),
			status: 1,
		});
```

```typescript
  /**
   * 退款回扣积分（v3 + spec §2.7-#21 原批次回写 + overflow 兜底）
   *
   * 规则：
   *   - 不扣成长值（growth_delta=0）
   *   - 允许负余额（user_members.points 已 ALTER 为 SIGNED；spec A1）
   *   - feature flag mall.refund.reverse_fifo:
   *       false → 旧逻辑（保持兼容）
   *       true  → 新逻辑（本方法主体）
   *   - 新逻辑账本公式：
   *       recoverHere = min(R, B.points - B.pR)
   *       overflow    = R - recoverHere   ≥ 0
   *       new B.pR    = B.pR + recoverHere（上限 = B.points）
   *       new M       = M + R              （SIGNED 可负）
   *       refund 流水: points=R, pointsRemaining=R, balance=new M,
   *                    expiresAt = B.expiresAt（继承，过期则立即过期）,
   *                    triggerEvent='mall_refund',
   *                    metadata.refundFromLogId = B.id
   *                    metadata.recoverHere / metadata.overflow
   */
  async refundPoints(
    userId: number,
    originalLogId: number,
    refundAmount: number,
    options: { remark?: string; transaction?: any } = {},
  ) {
    if (refundAmount <= 0) this.ctx.throw(400, '退款积分必须为正数');

    const ownTx = !options.transaction;
    const t: any = options.transaction || await (this.ctx.model as any).transaction();

    try {
      const original: any = await this.ctx.model.PointsLog.findByPk(originalLogId, {
        lock: t.LOCK.UPDATE, transaction: t,
      });
      if (!original) this.ctx.throw(404, '原积分流水不存在');
      if (original.userId !== userId) this.ctx.throw(403, '原流水不属于该用户');

      const member: any = await this.ctx.model.UserMember.findOne({
        where: { userId }, lock: t.LOCK.UPDATE, transaction: t,
      });
      if (!member) this.ctx.throw(404, '会员记录不存在');

      const newLogicEnabled = await this.getReverseFifoFlag();

      let recoverHere = 0;
      let overflow = 0;

      if (newLogicEnabled) {
        // ======= 新逻辑 =======
        const batchPoints       = Math.abs(original.points);
        const alreadyConsumed   = batchPoints - (original.pointsRemaining || 0);
        recoverHere             = Math.min(refundAmount, alreadyConsumed);
        overflow                = refundAmount - recoverHere;

        const newBatchRemaining = (original.pointsRemaining || 0) + recoverHere;
        // 是否同时修复 status：仅当原批次未过期 (now < expireAt) 且 recoverHere>0 才复活到 1
        const stillValid = !original.expireAt || new Date(original.expireAt).getTime() > Date.now();
        const newStatus = stillValid ? 1 : 2;  // 已过期保持 2，FIFO 跳过
        await original.update(
          { pointsRemaining: newBatchRemaining, status: newStatus },
          { transaction: t },
        );
      } else {
        // ======= 旧逻辑（flag=false 兼容分支）=======
        // 直接把退款额加回原批次的 pointsRemaining（不区分 alreadyConsumed）
        await original.update(
          { pointsRemaining: (original.pointsRemaining || 0) + refundAmount, status: 1 },
          { transaction: t },
        );
      }

      // ===== 会员余额加全 R（SIGNED）=====
      const newBalance = member.points + refundAmount;
      await member.update({ points: newBalance }, { transaction: t });

      // ===== 写 refund 流水 =====
      const metadata: any = newLogicEnabled
        ? {
            refundFromLogId: originalLogId,
            recoverHere,
            overflow,
          }
        : { refundFromLogId: originalLogId };

      const log: any = await this.ctx.model.PointsLog.create(
        {
          userId,
          type: 2,                               // 消费类（退款也作为"消费方向流水"，但 points 为正）
          orderType: 'refund',
          triggerEvent: 'mall_refund',           // Q-D=c 决策
          points: refundAmount,                  // 正数
          pointsRemaining: refundAmount,         // refund 流水自身额度 = R
          balance: newBalance,                   // SIGNED，可负
          growthDelta: 0,
          bizType: 'refund',
          bizId: String(originalLogId),
          remark: options.remark
            || `退款回扣原批次 #${originalLogId}（${newLogicEnabled ? `recoverHere=${recoverHere},overflow=${overflow}` : 'legacy'}）`,
          expireAt: original.expireAt,           // Q-C=a：继承原批次过期时间
          status: original.expireAt && new Date(original.expireAt).getTime() <= Date.now() ? 2 : 1,
          sourceLevelId: member.levelId,
          metadata,
        },
        { transaction: t },
      );

      if (ownTx) await t.commit();
      return { logId: log.id, balance: newBalance };
    } catch (err) {
      if (ownTx) await t.rollback();
      throw err;
    }
  }

  /**
   * 读取 refund 新逻辑 feature flag (Redis 60s 缓存, Q1=b 决策)
   *  - cache key: feature:refund_reverse_fifo
   *  - source: system_configs WHERE group='mall' AND key='refund.reverse_fifo'
   *  - admin 修改 system_configs 后须 await app.redis.del('feature:refund_reverse_fifo')
   */
  private async getReverseFifoFlag(): Promise<boolean> {
    const cacheKey = 'feature:refund_reverse_fifo';
    try {
      const cached = await (this.app as any).redis?.get(cacheKey);
      if (cached !== null && cached !== undefined) return cached === '1';
    } catch { /* redis 故障降级到 DB */ }

    let enabled = false;
    try {
      const rows: any[] = await (this.app.model as any).query(
        "SELECT `value` FROM `system_configs` WHERE `group`='mall' AND `key`='refund.reverse_fifo' LIMIT 1",
        { type: (this.app.model as any).QueryTypes.SELECT },
      );
      if (rows.length > 0) enabled = String(rows[0].value).toLowerCase() === 'true';
    } catch { /* ignore */ }

    try {
      await (this.app as any).redis?.set(cacheKey, enabled ? '1' : '0', 'EX', 60);
    } catch { /* ignore */ }
    return enabled;
  }
```

```typescript
/**
 * 字段白名单提取（admin 接口防字段注入）
 *  设计依据: docs/superpowers/specs/2026-05-27-积分成长体系后端优化设计文档.md §2.10
 */
export function pickFields<T extends Record<string, any>>(
	source: any,
	fields: readonly string[],
): Partial<T> {
	if (!source || typeof source !== 'object') return {};
	const result: any = {};
	for (const f of fields) {
		if (Object.prototype.hasOwnProperty.call(source, f)) {
			result[f] = source[f];
		}
	}
	return result;
}
```

```typescript
#!/usr/bin/env node
/**
 * 历史用户积分体系迁移脚本（一次性）
 *  设计依据: docs/superpowers/specs/2026-05-27-积分成长体系后端优化设计文档.md §6
 *
 *  目的：
 *    1. 按 growth_value 重新计算 user_members.levelId
 *    2. 现有 type=1 status=1 的 points_logs 补 expire_at（按当前等级 pointsExpireDays）
 *    3. 输出迁移报告 CSV
 *
 *  幂等：可重跑，已正确等级 / 已有 expire_at 跳过
 *
 *  使用：
 *    cd super-tool-node
 *    npx ts-node scripts/migrate_existing_users_points.ts --dry-run
 *    npx ts-node scripts/migrate_existing_users_points.ts --apply
 */
import { Application } from 'egg';
import * as fs from 'fs';

const args = process.argv.slice(2);
const DRY_RUN = !args.includes('--apply');

async function main() {
	const egg = require('egg');
	const app: Application = await egg.start({
		baseDir: process.cwd(),
		workers: 1,
	} as any);

	console.log(`[migrate] mode = ${DRY_RUN ? 'DRY-RUN' : 'APPLY'}`);

	const failures: any[] = [];
	let updated = 0;
	let skipped = 0;

	// 1) 分批读 user_members（1000 条一批）
	const BATCH = 1000;
	let offset = 0;
	while (true) {
		const members: any[] = await (app.model as any).UserMember.findAll({
			attributes: ['userId', 'levelId', 'growthValue'],
			order: [['user_id', 'ASC']],
			limit: BATCH,
			offset,
		});
		if (members.length === 0) break;

		for (const m of members) {
			try {
				await (app.model as any).transaction(async (t: any) => {
					// 计算正确 levelId
					const levels: any[] = await (app.model as any).MemberLevel.findAll({
						order: [['level', 'ASC']],
					});
					let correctLevelId = levels[0].id;
					for (const lv of levels) {
						if (m.growthValue >= (lv.growthThreshold || 0)) {
							correctLevelId = lv.id;
						}
					}

					if (correctLevelId === m.levelId) {
						skipped++;
						return;
					}

					// 拿到该等级的 pointsExpireDays
					const targetLevel = levels.find(l => l.id === correctLevelId);
					const benefits = targetLevel?.benefits || {};
					const expireDays = Number(benefits.points_expire_days) || 365;

					if (!DRY_RUN) {
						// 1) 更新 levelId
						await (app.model as any).UserMember.update(
							{ levelId: correctLevelId, levelCode: targetLevel.code },
							{ where: { userId: m.userId }, transaction: t },
						);

						// 2) 补 expire_at（仅对 expire_at IS NULL 的存量批次）
						const newExpireAt = new Date(Date.now() + expireDays * 86_400_000);
						const { Op } = require('sequelize');
						await (app.model as any).PointsLog.update(
							{ expireAt: newExpireAt },
							{
								where: {
									userId: m.userId,
									type: 1,
									status: 1,
									pointsRemaining: { [Op.gt]: 0 },
									expireAt: null,
								},
								transaction: t,
							},
						);
					}

					updated++;
					console.log(
						`[migrate] user=${m.userId} levelId ${m.levelId} → ${correctLevelId}`,
					);
				});
			} catch (err: any) {
				failures.push({ userId: m.userId, reason: err.message });
				console.error(`[migrate] user=${m.userId} FAIL: ${err.message}`);
			}
		}

		offset += BATCH;
		if (members.length < BATCH) break;
	}

	// 2) 输出报告
	const reportPath = `migration_report_${Date.now()}.csv`;

});
```

- 决策: **(α) 账本先行**
- 6 个 case 已 review 通过 → 现行 plan B1 文档即为账本契约

### 决策 5（Q-A）— 6 个 case 的预期值

- 决策: **全同意**（review 复算 6/6 case 数学一致）
- 唯一措辞修正: Case 6 的场景描述从"SIGNED 关键场景"改为"跨批次回写：B1 消费完 + 部分 B2"

### 决策 6（Q-B）— overflow 边界处理

- 选项: **(a) 允许兜底（差额加到会员余额）** / (b) 拒绝并报错
- 决策: **(a) 允许兜底**
- 理由: 极少发生（订单退款金额 > 该笔订单消费的积分），但出现时拒绝会让用户卡单；改为 silent overflow + metadata 记录便于后续审计
- 落地: `recoverHere = min(R, B.alreadyConsumed)`, `overflow = R - recoverHere`，两值都写入 `points_logs.metadata`

### 决策 7（Q-C）— refund 流水 expiresAt

- 选项: **(a) 继承原批次 expiresAt** / (b) now+365天 / (c) 复用当前等级 pointsExpireDays
- 决策: **(a) 继承原批次**
- 理由: 与"积分有效期不可延长"的业务原则一致；防止用户通过"先消费后退款"刷续期
- 副作用: 若原批次已过期，refund 流水 status=2 + 立即过期，FIFO 永不命中（="过期分退给你了，但你立刻就过期"），符合"退款 ≠ 重新发分"的语义

### 决策 8（Q-D）— triggerEvent 字段值

- 选项: (a) `REFUND_FROM_BATCH_${B.id}` / (b) `refund` / **(c) `mall_refund`**
- 决策: **(c) `mall_refund`**
- 理由: 语义化 + 与现有 triggerEvent 命名风格（`mall_exchange` / `first_consume` / `sign_streak`）一致；原批次 id 放 `metadata.refundFromLogId`，避免 triggerEvent 字段长度膨胀
