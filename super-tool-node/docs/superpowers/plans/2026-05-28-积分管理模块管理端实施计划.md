# 积分管理模块（管理端）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 super-tools-admin 中建设独立的「积分管理」顶级模块，覆盖规则、任务、商城、流水、运维、看板、调整、事件追溯、退款账本 9 个页面，并完整接入 RBAC（菜单、按钮、API 三级权限）。

**Architecture:** 后端复用 [router.ts](../../app/router.ts) §积分体系（管理端）已有路由，仅新增 `database/028_add_points_admin_permissions.sql` 落 RBAC 三级权限码（顶级目录 + 二级菜单 + 按钮 + 兜底 API）。前端按 [config/routes/modules/notification.ts](../../../super-tools-admin/config/routes/modules/notification.ts) 与 [pages/Notification/](../../../super-tools-admin/src/pages/Notification) 范式新建 `routes/modules/points.ts` + `pages/Points/*` + `services/points.ts`，每个页面挂 `<AuthWrapper>`，写操作按钮挂 `<AuthButton permCode>`。

**Tech Stack:** UmiJS 4 + Ant Design 5 + Dva + TypeScript（admin 端），Egg.js + Sequelize + MySQL（后端），无新增依赖。
