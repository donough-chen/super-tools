# 积分与成长体系 MVP 实施计划 v2

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有会员体系基础上，构建完整的"获取-累积-消耗-过期"积分生命周期，含任务中心（事件驱动）、签到（连续+断签归零）、积分商城（虚拟为主，实物字段预留）、FIFO 过期（按等级延长有效期）、抵扣（等级阶梯上限）、对账与提醒幂等六大模块；并和现有等级体系形成"积分倍率 + 任务加成 + 升级礼包 + 升级延长积分有效期"协同闭环。

**Architecture:** 采用"事件驱动 + 任务模板 + 单表 FIFO"。业务模块通过 `app.messenger`（worker 内）+ Service 直接调用（worker 间通过 DB 落地实现最终一致）触发领域事件，TaskService 监听事件匹配任务条件并写进度；积分获取/消耗均落 `points_logs`（通过新增的 `points_remaining/status/source_level_id` 字段直接承担批次能力），消耗按 FIFO 扣 `points_remaining`，过期由定时任务扫描清零并写出独立的 `points_expiry_logs` 执行记录；提醒通过 `points_expiry_notices` 保证幂等；日终通过 `points_daily_snapshots` 做余额对账；商城通过 `product_snapshot` 列冻结快照防止配置漂移。

**Tech Stack:** Egg.js (TypeScript) + Sequelize + MySQL 8 + Redis + node-schedule（egg-schedule）+ 现有 notification 服务（多渠道发送）

## 决策摘要（基于评估报告 + 用户回复）

| 决策项         | 选择                                                                                                                                | 依据                       |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 成长值 vs 积分 | 强解耦（按行为独立配置矩阵，不再耦合死）                                                                                            | 评估报告 §3 行为矩阵       |
| 任务模型       | 事件驱动 + 任务模板表（`tasks` + `user_tasks` + `task_completion_logs`）                                                            | 评估报告 §6 任务中心       |
| 商品形态       | **纯虚拟为主，实物字段（receiver*\*, express*\*）nullable 预留**                                                                    | 用户回复 Q1=A              |
| FIFO 数据载体  | **`points_logs` 单表融合**（`points_remaining` / `status` / `source_level_id`），废弃 `points_batches`                              | 用户回复 Q2=A，评估报告 §5 |
| 积分有效期     | **按当前等级延长**：青铜/白银 365、黄金 456、铂金 548、钻石 730 天；升级时存量积分 `expire_at = GREATEST(原值, NOW + 新等级有效期)` | 评估报告 §4.4              |
| 积分倍率       | **按等级**：青铜 1× / 白银 1.1× / 黄金 1.3× / 铂金 1.5× / 钻石 2× / 黑金 3×                                                         | 评估报告 §4.2              |
| 任务奖励加成   | 0% / 5% / 10% / 20% / 30% / 50%（按等级）                                                                                           | 评估报告 §4.2              |
| 签到加成       | 每日基础积分 1 / 2 / 3 / 5 / 7 / 10（按等级）                                                                                       | 评估报告 §4.2              |
| 升级礼包       | 白银 +200 / 黄金 +500 / 铂金 +1000 / 钻石 +2000；**礼包成长值不计入升级累计**（防连锁升级）                                         | 评估报告 §4.3              |
| 抵扣上限       | free 5% / silver 10% / gold 20% / diamond 30% / black 50%                                                                           | 评估报告 §3.4              |
| 每日上限       | 任务类 50 积分/天，邀请类 5 笔/天，消费类不限                                                                                       | 评估报告 §3.5              |
| 退款规则       | **退款不扣成长值**，按"原获得倍率"扣回积分（含已消耗的部分允许负余额）                                                              | 评估报告 §5.2              |
| 提醒触达       | T-30 站内信+Push / T-7 SMS+Push / T-0 全渠道；通过 `points_expiry_notices` 唯一约束保幂等                                           | 评估报告 §5.4              |
| 对账机制       | 每日 23:55 写 `points_daily_snapshots` 全量快照；每小时巡检"理论余额 vs 实际余额"，差异落告警                                       | 评估报告 §5.5              |
| 缓存策略       | home/level 60-300s 用户维度；mall/products 60-300s 全局；logs 不缓存；积分变动→清 points/\*                                         | 评估报告 §8.1              |
| 限流           | signin 1/天（业务）；claim 10/min；exchange 5/min；GET 100/min/user；全局 200/min/IP                                                | 评估报告 §8.2              |
| 幂等           | 所有写接口支持 `Idempotency-Key`（客户端 UUID v4，服务端 24h 缓存首次响应）                                                         | 评估报告 §8.3              |
| 历史用户迁移   | 全量按当前 `growth_value` 重算等级；**不补发升级礼包**；存量积分 `expire_at` 按当前等级补齐至少剩余 30 天                           | 评估报告 §10 + 工程兜底    |

## Task 1: 数据库迁移脚本

**Files:**

- Create: `database/025_add_points_growth_system.sql`

**核心要点：**

- `points_logs` 融合 FIFO 字段（`points_remaining`、`status`、`source_level_id`、`source_event`、`growth_multiplier`），废弃独立的 `points_batches` 表
- 新增 9 张表：tasks / user_tasks / task_completion_logs / user_signs / points_mall_items / points_mall_orders / daily_points_caps / points_expiry_logs / points_expiry_notices / points_daily_snapshots
- `points_mall_orders` 增加 `product_snapshot`（JSON，下单时冻结的商品快照）+ 实物预留列（`receiver_name/phone/address/express_company/express_no`，全部 nullable）
- ALTER `user_members`：新增 `sign_streak / last_sign_date / total_sign_days`
- 种子数据：18 条任务（按行为矩阵）+ 7 个商城商品 + 10 条 points 系统配置 + 11 个权限码 + 6 个通知类型 + 等级倍率/有效期/礼包配置（写入 `member_levels.benefits` 的 JSON 扩展键）

- [ ] **Step 1: 创建迁移脚本**

```sql
-- ============================================================
-- 迁移脚本: 025_add_points_growth_system.sql
-- 版本: 2.3.0
-- 创建时间: 2026-05-26
-- 说明: 积分与成长体系 MVP（FIFO 单表融合 + 任务 + 商城 + 对账）
-- 设计依据: docs/analysis/积分与成长体系深度评估报告.md
-- ============================================================

USE `superadmin_db`;

SET NAMES utf8mb4;
SET FOREIGN_KEY_CHECKS = 0;


-- ------------------------------------------------------------
-- A. ALTER points_logs（融合 FIFO 字段，单表承担"流水 + 批次"双职责）
-- 决策: 用户回复 Q2=A
-- ------------------------------------------------------------
ALTER TABLE `points_logs`
  ADD COLUMN `points_remaining`  INT UNSIGNED      NOT NULL DEFAULT 0
    COMMENT '剩余可用积分（仅 type=1 时有效，FIFO 消耗）'                     AFTER `balance`,
  ADD COLUMN `status`            TINYINT UNSIGNED  NOT NULL DEFAULT 1
    COMMENT '状态:1可用,2已耗尽,3已过期,4已退款回收（仅 type=1 时有效）'        AFTER `points_remaining`,
  ADD COLUMN `source_level_id`   INT UNSIGNED      DEFAULT NULL
    COMMENT '获得时的等级ID（用于计算过期时长）'                                AFTER `status`,
  ADD COLUMN `source_event`      VARCHAR(50)       DEFAULT NULL
    COMMENT '触发事件 code（task_claim/order_paid/sign/admin_adjust 等）'      AFTER `source_level_id`,
  ADD COLUMN `growth_multiplier` DECIMAL(4,2)      NOT NULL DEFAULT 1.00
    COMMENT '获得时应用的等级积分倍率（用于退款回算）'                          AFTER `source_event`,
  ADD INDEX `idx_user_status_expire` (`user_id`, `status`, `expire_at`),
  ADD INDEX `idx_status_expire` (`status`, `expire_at`);


-- ------------------------------------------------------------
-- B. ALTER user_members（签到 3 字段）
-- ------------------------------------------------------------
ALTER TABLE `user_members`
  ADD COLUMN `sign_streak`     INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '当前连续签到天数'   AFTER `points`,
  ADD COLUMN `last_sign_date`  DATE         DEFAULT NULL       COMMENT '最后签到日期'       AFTER `sign_streak`,
  ADD COLUMN `total_sign_days` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '累计签到总天数'     AFTER `last_sign_date`;


-- ------------------------------------------------------------
-- 1. 任务定义表
-- ------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `tasks` (
  `id`              INT UNSIGNED      NOT NULL AUTO_INCREMENT,
  `code`            VARCHAR(50)       NOT NULL COMMENT '任务唯一码',
  `name`            VARCHAR(100)      NOT NULL COMMENT '任务名称',
  `icon`            VARCHAR(500)      DEFAULT NULL,
  `description`     VARCHAR(500)      DEFAULT NULL,
  `category`        ENUM('newbie','daily','weekly','monthly','yearly','achievement','activity') NOT NULL,
  `trigger_event`   VARCHAR(50)       NOT NULL COMMENT '监听的领域事件 code',
  `condition`       JSON              DEFAULT NULL COMMENT '过滤条件（JSON）',
  `progress_target` INT UNSIGNED      NOT NULL DEFAULT 1,
  `progress_type`   TINYINT UNSIGNED  NOT NULL DEFAULT 1
    COMMENT '进度计算:1计数累加,2去重计数,3累计金额阈值,4直接覆盖（连续天数）',
  `reward_points`   INT UNSIGNED      NOT NULL DEFAULT 0,
  `reward_growth`   INT UNSIGNED      NOT NULL DEFAULT 0,
  `reward_extra`    JSON              DEFAULT NULL,
  `reset_cycle`     ENUM('once','daily','weekly','monthly','yearly') NOT NULL DEFAULT 'once',
  `valid_from`      DATETIME          DEFAULT NULL,
  `valid_to`        DATETIME          DEFAULT NULL,
  `required_level`  VARCHAR(30)       DEFAULT NULL,
  `daily_cap_group` VARCHAR(30)       DEFAULT NULL COMMENT '日上限分组(task/invite)',
  `expire_days`     INT UNSIGNED      DEFAULT NULL COMMENT '任务自身过期天数（如新手任务30天）',
  `sort`            INT               NOT NULL DEFAULT 0,
  `status`          TINYINT UNSIGNED  NOT NULL DEFAULT 1,
  `created_at`      DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`      DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`),
  INDEX `idx_trigger_event` (`trigger_event`),
  INDEX `idx_category_status` (`category`, `status`),
  INDEX `idx_status_sort` (`status`, `sort`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='任务定义表';


-- ------------------------------------------------------------
-- 2. 用户任务进度表
-- ------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `user_tasks` (
  `id`            BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT,
  `user_id`       BIGINT UNSIGNED   NOT NULL,
  `task_code`     VARCHAR(50)       NOT NULL,
  `cycle_key`     VARCHAR(20)       NOT NULL COMMENT '周期键(once/2026-05-26/2026-W21/2026-05/2026)',
  `progress`      INT UNSIGNED      NOT NULL DEFAULT 0,
  `progress_meta` JSON              DEFAULT NULL COMMENT '辅助元数据（去重值集合/累计金额/连续天数等）',
  `status`        ENUM('pending','completed','claimed','expired') NOT NULL DEFAULT 'pending',
  `expire_at`     DATETIME          DEFAULT NULL COMMENT '任务到期时间（覆盖任务自身 expire_days）',
  `completed_at`  DATETIME          DEFAULT NULL,
  `claimed_at`    DATETIME          DEFAULT NULL,
  `created_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_task_cycle` (`user_id`, `task_code`, `cycle_key`),
  INDEX `idx_user_status` (`user_id`, `status`),
  INDEX `idx_status_completed` (`status`, `completed_at`),
  INDEX `idx_expire_at` (`expire_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户任务进度表';


-- ------------------------------------------------------------
-- 3. 任务完成记录表（领奖前的"已完成快照"，便于补发与审计）
-- ------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `task_completion_logs` (
  `id`            BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT,
  `user_task_id`  BIGINT UNSIGNED   NOT NULL,
  `user_id`       BIGINT UNSIGNED   NOT NULL,
  `task_code`     VARCHAR(50)       NOT NULL,
  `cycle_key`     VARCHAR(20)       NOT NULL,
  `reward_points` INT UNSIGNED      NOT NULL DEFAULT 0 COMMENT '已应用等级加成后的实发积分',
  `reward_growth` INT UNSIGNED      NOT NULL DEFAULT 0,
  `bonus_rate`    DECIMAL(4,2)      NOT NULL DEFAULT 1.00 COMMENT '等级任务加成倍率',
  `status`        ENUM('pending','rewarded','failed') NOT NULL DEFAULT 'pending',
  `points_log_id` BIGINT UNSIGNED   DEFAULT NULL COMMENT '关联 points_logs.id（积分发放后回填）',
  `error_msg`     VARCHAR(500)      DEFAULT NULL,
  `retry_count`   INT UNSIGNED      NOT NULL DEFAULT 0,
  `next_retry_at` DATETIME          DEFAULT NULL,
  `created_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_task_id` (`user_task_id`),
  INDEX `idx_status_retry` (`status`, `next_retry_at`),
  INDEX `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='任务完成记录（补发用）';


-- ------------------------------------------------------------
-- 4. 用户签到记录表
-- ------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `user_signs` (
  `id`              BIGINT UNSIGNED  NOT NULL AUTO_INCREMENT,
  `user_id`         BIGINT UNSIGNED  NOT NULL,
  `sign_date`       DATE             NOT NULL,
  `streak`          INT UNSIGNED     NOT NULL DEFAULT 1,
  `points_earned`   INT UNSIGNED     NOT NULL DEFAULT 0,
```

**Files:**

**职责：** 唯一负责"读 `member_levels.benefits` JSON、计算应用倍率/加成/上限/礼包"的服务。其他服务（member/sign/task/order）一律调它，避免规则散落。

- [ ] **Step 1: 创建 PointsRuleService**

```typescript
// app/service/pointsRule.ts
import BaseService from './base';

export interface LevelRule {
	pointsMultiplier: number; // 1.0 / 1.1 / 1.3 / 2.0 / 3.0
	taskBonusRate: number; // 0 / 0.05 / 0.10 / 0.30 / 0.50
	signBasePoints: number; // 1 / 2 / 3 / 5 / 10
	pointsExpireDays: number; // 365 / 456 / 730
	upgradeGiftPoints: number;
	upgradeGiftGrowth: number;
	deductLimit: number; // 0.05 / 0.10 / 0.20 / 0.50
}

export default class PointsRuleService extends BaseService {
	/** 读取等级规则（带 5 分钟内存缓存） */
	async getLevelRule(levelId: number): Promise<LevelRule> {
		const cacheKey = `pointsRule:level:${levelId}`;
		const cached = (this.app as any)._levelRuleCache?.[cacheKey];
		if (cached && cached.expireAt > Date.now()) return cached.value;

		const level = await this.ctx.model.MemberLevel.findByPk(levelId);
		if (!level) throw new Error(`Level not found: ${levelId}`);
		const benefits: any = (level as any).benefits || {};
		const rule: LevelRule = {
			pointsMultiplier: Number(benefits.points_multiplier ?? 1),
			taskBonusRate: Number(benefits.task_bonus_rate ?? 0),
			signBasePoints: Number(benefits.sign_base_points ?? 1),
			pointsExpireDays: Number(benefits.points_expire_days ?? 365),
			upgradeGiftPoints: Number(benefits.upgrade_gift_points ?? 0),
			upgradeGiftGrowth: Number(benefits.upgrade_gift_growth ?? 0),
			deductLimit: Number(benefits.deduct_limit ?? 0.05),
		};

		(this.app as any)._levelRuleCache = (this.app as any)._levelRuleCache || {};
		(this.app as any)._levelRuleCache[cacheKey] = {
			value: rule,
			expireAt: Date.now() + 300_000,
		};
		return rule;
	}

	/** 应用积分倍率（消费类积分获得才用，签到/任务奖励不叠加倍率） */
	applyMultiplier(
		basePoints: number,
		rule: LevelRule,
		options?: { applyMultiplier?: boolean },
	): number {
		if (!options?.applyMultiplier) return basePoints;
		return Math.floor(basePoints * rule.pointsMultiplier);
	}

	/** 应用任务加成（仅任务领奖时用） */
	applyTaskBonus(basePoints: number, rule: LevelRule): number {
		return Math.floor(basePoints * (1 + rule.taskBonusRate));
	}

	/** 计算签到当日积分（基础积分 + 连续奖励里程碑积分另由任务系统派发） */
	calcSignBasePoints(rule: LevelRule): number {
		return rule.signBasePoints;
	}

	/** 计算积分有效期 */
	calcExpireAt(rule: LevelRule, from: Date = new Date()): Date {
		return new Date(from.getTime() + rule.pointsExpireDays * 86400000);
	}

	/** 计算抵扣上限（元） */
	calcDeductLimit(orderAmount: number, rule: LevelRule): number {
		return Math.floor(orderAmount * rule.deductLimit * 100) / 100;
	}

	/** 失效缓存（管理端配置变更时调用） */
	invalidateCache(levelId?: number) {
		if (!levelId) (this.app as any)._levelRuleCache = {};
		else
			delete (this.app as any)._levelRuleCache?.[`pointsRule:level:${levelId}`];
	}
}
```

```typescript
// app/service/member.ts （仅展示改造关键段）
async addPoints(
  userId: number,
  points: number,
  source: string,
  options: {
    growthDelta?: number;
    bizType?: string;
    bizId?: string;
    remark?: string;
    applyMultiplier?: boolean;   // 仅消费场景置 true
    event?: string;              // 来源事件 code
    skipGrowth?: boolean;        // 升级礼包用：成长值不计入升级累计
    transaction?: any;
  } = {},
) {
  const t = options.transaction || await this.ctx.model.transaction();
  const ownTx = !options.transaction;

  try {
    const member = await this.ctx.model.UserMember.findOne({
      where: { userId }, lock: t.LOCK.UPDATE, transaction: t,
    });
    if (!member) throw new Error('用户会员记录不存在');
    const m: any = member;

    // 1) 应用等级倍率
    const rule = await this.ctx.service.pointsRule.getLevelRule(m.levelId);
    const realPoints = options.applyMultiplier
      ? this.ctx.service.pointsRule.applyMultiplier(points, rule, { applyMultiplier: true })
      : points;
    const realGrowth = options.growthDelta ?? 0;

    // 2) 更新会员余额（成长值在 skipGrowth 时不计入）
    const newBalance = m.points + realPoints;
    const updateData: any = { points: newBalance, totalPoints: m.totalPoints + Math.max(0, realPoints) };
    if (!options.skipGrowth && realGrowth !== 0) {
      updateData.growthValue = m.growthValue + realGrowth;
    }
    await m.update(updateData, { transaction: t });

    // 3) 写 FIFO 流水
    const expireAt = realPoints > 0 ? this.ctx.service.pointsRule.calcExpireAt(rule) : null;
    const log = await this.ctx.model.PointsLog.create({
      userId,
      type: realPoints > 0 ? 1 : (realPoints < 0 ? 2 : 4),
      source,
      points: realPoints,
      balance: newBalance,
      growthDelta: options.skipGrowth ? 0 : realGrowth,
      bizType: options.bizType,
      bizId: options.bizId,
      remark: options.remark,
      expireAt,
      pointsRemaining: realPoints > 0 ? realPoints : 0,
      status: realPoints > 0 ? 1 : 2,
      sourceLevelId: m.levelId,
      sourceEvent: options.event || source,
      growthMultiplier: rule.pointsMultiplier,
    }, { transaction: t });

    // 4) 升级判断（skipGrowth 不参与）
    if (!options.skipGrowth) {
      await this.checkAndUpgrade(userId, t);
    }

    // 5) 触发领域事件（让 TaskService 累进度）
    if (realPoints > 0) {
      await this.ctx.service.event.emit('points_earned', {
        userId, points: realPoints, source, event: options.event || source,
      });
    }

    if (ownTx) await t.commit();
    return { logId: (log as any).id, balance: newBalance, realPoints };
  } catch (err) {
    if (ownTx) await t.rollback();
    throw err;
  }
}
```

```typescript
async consumePoints(
  userId: number,
  amount: number,
  source: string,
  options: {
    bizType?: string; bizId?: string; remark?: string;
    event?: string; transaction?: any; allowNegative?: boolean;
  } = {},
) {
  if (amount <= 0) throw new Error('消耗金额必须大于 0');
  const t = options.transaction || await this.ctx.model.transaction();
  const ownTx = !options.transaction;
  const { Op } = require('sequelize');

  try {
    const member = await this.ctx.model.UserMember.findOne({
      where: { userId }, lock: t.LOCK.UPDATE, transaction: t,
    });
    if (!member) throw new Error('用户会员记录不存在');
    const m: any = member;
    if (!options.allowNegative && m.points < amount) {
      throw new Error('积分余额不足');
    }

    // FIFO 扣减
    let remaining = amount;
    const batches = await this.ctx.model.PointsLog.findAll({
      where: { userId, status: 1, pointsRemaining: { [Op.gt]: 0 } },
      order: [['expire_at', 'ASC'], ['id', 'ASC']],
      lock: t.LOCK.UPDATE, transaction: t,
    });
    for (const b of batches) {
      if (remaining <= 0) break;
      const bb: any = b;
      const deduct = Math.min(remaining, bb.pointsRemaining);
      const newRemaining = bb.pointsRemaining - deduct;
      await bb.update({
        pointsRemaining: newRemaining,
        status: newRemaining === 0 ? 2 : 1,
      }, { transaction: t });
      remaining -= deduct;
    }
    // 余额不足且允许负余额 → 剩余的 remaining 视为透支（仅退款场景），不再扣批次

    const newBalance = m.points - amount;
    await m.update({ points: Math.max(0, newBalance) }, { transaction: t });

    const log = await this.ctx.model.PointsLog.create({
      userId, type: 2, source,
      points: -amount, balance: Math.max(0, newBalance),
      growthDelta: 0,
      bizType: options.bizType, bizId: options.bizId, remark: options.remark,
      pointsRemaining: 0, status: 2,
      sourceLevelId: m.levelId,
      sourceEvent: options.event || source,
    }, { transaction: t });

    if (ownTx) await t.commit();
    return { logId: (log as any).id, balance: Math.max(0, newBalance) };
  } catch (err) {
    if (ownTx) await t.rollback();
    throw err;
  }
}
```

```typescript
async checkAndUpgrade(userId: number, transaction?: any) {
  const t = transaction || await this.ctx.model.transaction();
  const ownTx = !transaction;
  try {
    const member: any = await this.ctx.model.UserMember.findOne({
      where: { userId }, lock: t.LOCK.UPDATE, transaction: t,
    });
    if (!member) return;

    // 找到当前 growthValue 满足的最高等级
    const targetLevel: any = await this.ctx.model.MemberLevel.findOne({
      where: { upgradeGrowth: { [require('sequelize').Op.lte]: member.growthValue }, status: 1 },
      order: [['level', 'DESC']],
    });
    if (!targetLevel || targetLevel.id === member.levelId) {
      if (ownTx) await t.commit();
      return;
    }

    const oldLevelId = member.levelId;
    await member.update({ levelId: targetLevel.id, levelCode: targetLevel.code }, { transaction: t });

    const newRule = await this.ctx.service.pointsRule.getLevelRule(targetLevel.id);

    // 1) 发升级礼包（skipGrowth=true 防连锁升级）
    if (newRule.upgradeGiftPoints > 0) {
      await this.addPoints(userId, newRule.upgradeGiftPoints, 'level_upgrade_gift', {
        event: 'level_upgrade_gift', skipGrowth: true,
        remark: `升级到 ${targetLevel.name} 赠送积分`,
        transaction: t,
      });
    }

    // 2) 延长存量积分有效期
    await this.ctx.service.pointsExpire.extendExpireOnUpgrade(userId, newRule, t);

    // 3) 触发升级事件（通知 + 任务）
    await this.ctx.service.event.emit('level_up', {
      userId, oldLevelId, newLevelId: targetLevel.id, newLevelCode: targetLevel.code,
    });
    try {
      await (this.ctx.service.notification as any).core.send({
        typeCode: 'BUSINESS_LEVEL_UP', userId,
        variables: { levelName: targetLevel.name, giftPoints: newRule.upgradeGiftPoints },
      });
    } catch { /* ignore */ }

    if (ownTx) await t.commit();
  } catch (err) {
    if (ownTx) await t.rollback();
    throw err;
  }
}
```

```typescript
async refundPoints(
  userId: number,
  originalLogId: number,
  refundAmount: number,
  options: { remark?: string; transaction?: any } = {},
) {
  const t = options.transaction || await this.ctx.model.transaction();
  const ownTx = !options.transaction;
  try {
    const original: any = await this.ctx.model.PointsLog.findByPk(originalLogId, { transaction: t });
    if (!original) throw new Error('原积分流水不存在');

    // 优先扣回原批次的 points_remaining
    const member: any = await this.ctx.model.UserMember.findOne({
      where: { userId }, lock: t.LOCK.UPDATE, transaction: t,
    });
    let toRecover = refundAmount;
    if (original.status === 1 && original.pointsRemaining > 0) {
      const recoverFromBatch = Math.min(toRecover, original.pointsRemaining);
      await original.update({
        pointsRemaining: original.pointsRemaining - recoverFromBatch,
        status: original.pointsRemaining - recoverFromBatch === 0 ? 4 : 1,
      }, { transaction: t });
      toRecover -= recoverFromBatch;
    }

    // 剩下的（已被消耗）：直接扣会员余额，允许负余额
    const newBalance = member.points - refundAmount;
    await member.update({ points: newBalance }, { transaction: t });

    await this.ctx.model.PointsLog.create({
      userId, type: 2, source: 'refund',
      points: -refundAmount, balance: newBalance,
      growthDelta: 0,                       // 不扣成长值
      bizType: 'refund', bizId: String(originalLogId),
      remark: options.remark || `退款扣回原批次 #${originalLogId}`,
      pointsRemaining: 0, status: 2,
      sourceLevelId: member.levelId,
      sourceEvent: 'refund',
    }, { transaction: t });

    if (ownTx) await t.commit();
    return { balance: newBalance };
  } catch (err) {
    if (ownTx) await t.rollback();
    throw err;
  }
}
```

```typescript
import BaseService from './base';

export interface DomainEvent {
	code: string;
	userId: number;
	payload?: any;
	ts?: number;
}

export default class EventService extends BaseService {
	async emit(
		code: string,
		payload: { userId: number; [k: string]: any },
	): Promise<void> {
		const evt: DomainEvent = {
			code,
			userId: payload.userId,
			payload,
			ts: Date.now(),
		};
		// 同步派发本进程订阅者（TaskService）

			await (this.ctx.service.task as any).onEvent(evt);
		} catch (err: any) {
			this.ctx.logger.error(

			);

		// 跨 worker 广播（多 worker 都能收到，但只有 1 个 worker 实际处理：见 TaskService.onEvent 内 SELECT FOR UPDATE 防重）
		try {
			(this.app as any).messenger.sendToApp('domain-event', evt);

		}
	}
}
```

## Task 7: 任务中心服务 TaskService

**Files:**

- Create: `app/service/task.ts`

**核心方法：**

- `onEvent(evt)` ——事件分发入口，按 `trigger_event` 匹配启用任务，按 `progress_type` 累进度
- `listUserTasks(userId, filter)` ——C 端列表（自动按周期 key 拼装，未存在则即时创建 pending 行）
- `claim(userId, taskCode)` ——领奖：写 `task_completion_logs` → 调 `member.addPoints(rewardPoints * (1+taskBonusRate), 'task_reward', { skipGrowth: false, growthDelta: rewardGrowth })` → 状态置 `claimed`/`rewarded`
- `expireNewbieTasks()` ——定时任务用：把超过 30 天未完成的新手任务置 `expired`

**进度类型实现要点：**
| progressType | 累进逻辑 |
| --- | --- |
| 1 计数累加 | `progress = progress + 1` |
| 2 去重计数 | `progressMeta.distinctSet` 添加 payload[distinct_field]，`progress = set.size` |
| 3 累计阈值 | `progress = progress + payload.amount`（用累计金额，与 progressTarget 阈值比较） |
| 4 直接覆盖 | `progress = max(progress, payload.streak)`（连续签到达成最大值） |

- [ ] **Step 1: 创建 TaskService**

```typescript
// app/service/task.ts
import BaseService from './base';

const cycleKey = (cycle: string, d: Date = new Date()) => {
	const y = d.getUTCFullYear();
	const m = String(d.getUTCMonth() + 1).padStart(2, '0');
	const day = String(d.getUTCDate()).padStart(2, '0');
	switch (cycle) {
		case 'once':
			return 'once';
		case 'daily':
			return `${y}-${m}-${day}`;
		case 'weekly': {
			const onejan = new Date(Date.UTC(y, 0, 1));
			const week = Math.ceil(
				((+d - +onejan) / 86400000 + onejan.getUTCDay() + 1) / 7,
			);
			return `${y}-W${String(week).padStart(2, '0')}`;
		}
		case 'monthly':
			return `${y}-${m}`;
		case 'yearly':
			return `${y}`;
		default:
			return 'once';
	}
};

export default class TaskService extends BaseService {
	/** 事件入口（被 EventService.emit + messenger 双触发，靠唯一索引幂等） */
	async onEvent(evt: { code: string; userId: number; payload?: any }) {
		const tasks = await this.ctx.model.Task.findAll({
			where: { triggerEvent: evt.code, status: 1 },
			order: [['sort', 'ASC']],
		});
		for (const task of tasks) {
			try {
				await this.applyEventToTask(task, evt);
			} catch (err: any) {
				this.ctx.logger.error(
					`[task:${(task as any).code}] apply error: ${err.message}`,
					err,
				);
			}
		}
	}

	private async applyEventToTask(task: any, evt: any) {
		// 条件过滤
		if (
			task.condition?.amount &&
			Number(evt.payload?.amount || 0) < Number(task.condition.amount) &&
			task.progressType !== 3
		)
			return;
		if (
			task.condition?.streak &&
			Number(evt.payload?.streak || 0) < Number(task.condition.streak) &&
			task.progressType !== 4
		)
			return;
		if (task.requiredLevel) {
			const m: any = await this.ctx.model.UserMember.findOne({
				where: { userId: evt.userId },
			});
			if (!m || m.levelCode !== task.requiredLevel) return;
		}

		const ck = cycleKey(task.resetCycle);

		return await this.ctx.model.transaction(async (t: any) => {
			const [ut, created] = await (this.ctx.model.UserTask as any).findOrCreate(
				{
					where: { userId: evt.userId, taskCode: task.code, cycleKey: ck },
					defaults: {
						userId: evt.userId,
						taskCode: task.code,
						cycleKey: ck,
						progress: 0,
						status: 'pending',
						progressMeta: task.progressType === 2 ? { distinctSet: [] } : null,
						expireAt: task.expireDays
							? new Date(Date.now() + task.expireDays * 86400000)
							: null,
					},
					transaction: t,
					lock: t.LOCK.UPDATE,
				},
			);
			if (
				ut.status === 'completed' ||
				ut.status === 'claimed' ||
				ut.status === 'expired'
			)
				return;

			let newProgress = ut.progress;
			let newMeta = ut.progressMeta || null;
			switch (task.progressType) {
				case 1:
					newProgress = ut.progress + 1;
					break;
				case 2: {
					const distinctField = task.condition?.distinct_field || 'tool_code';
					const set = new Set<string>(newMeta?.distinctSet || []);
					const val = String(evt.payload?.[distinctField] ?? '');
					if (val) set.add(val);
					newMeta = { distinctSet: [...set] };
					newProgress = set.size;
					break;
				}
				case 3:
					newProgress = ut.progress + Number(evt.payload?.amount || 0);
					break;
				case 4:
					newProgress = Math.max(ut.progress, Number(evt.payload?.streak || 0));
					break;
			}

			const completed = newProgress >= task.progressTarget;
			await ut.update(
				{
					progress: newProgress,
					progressMeta: newMeta,
					status: completed ? 'completed' : 'pending',
					completedAt: completed ? new Date() : null,
				},
				{ transaction: t },
			);

			if (completed) {
				// 写 completion log（pending → 等待用户 claim）
				await (this.ctx.model.TaskCompletionLog as any).findOrCreate({
					where: { userTaskId: ut.id },
					defaults: {
						userTaskId: ut.id,
						userId: ut.userId,
						taskCode: ut.taskCode,
						cycleKey: ut.cycleKey,
						rewardPoints: 0,
						rewardGrowth: 0,
						bonusRate: 1.0,
						status: 'pending',
					},
					transaction: t,
				});
				try {
					await (this.ctx.service.notification as any).core.send({
						typeCode: 'BUSINESS_TASK_COMPLETED',
						userId: ut.userId,
						variables: { taskName: task.name, rewardPoints: task.rewardPoints },
					});
				} catch {
					/* ignore */
				}
			}
		});
	}

	/** 用户领奖 */
	async claim(userId: number, taskCode: string) {
		return await this.ctx.model.transaction(async (t: any) => {
			const task: any = await this.ctx.model.Task.findOne({
				where: { code: taskCode, status: 1 },
			});
			if (!task) throw new Error('任务不存在');

			const ck = cycleKey(task.resetCycle);
			const ut: any = await this.ctx.model.UserTask.findOne({
				where: { userId, taskCode, cycleKey: ck },
				lock: t.LOCK.UPDATE,
				transaction: t,
			});
			if (!ut) throw new Error('任务尚未达成');
			if (ut.status === 'claimed') throw new Error('已领取');
			if (ut.status !== 'completed') throw new Error('任务未完成');

			// 检查每日上限（task 类）
			if (task.dailyCapGroup === 'task') {
				const today = new Date().toISOString().slice(0, 10);
				const cap: any = await this.ctx.model.DailyPointsCap.findOne({
					where: { userId, capDate: today, capGroup: 'task' },
					lock: t.LOCK.UPDATE,
					transaction: t,
				});
				const taskCapLimit = Number(
					(await this.app.config.systemConfigGet?.(
						'points',
						'daily_cap_task',
					)) || 50,
				);
				if (cap && cap.earned >= taskCapLimit)
					throw new Error('今日任务积分已达上限');
			}

			// 应用任务加成
			const member: any = await this.ctx.model.UserMember.findOne({
				where: { userId },
				transaction: t,
			});
			const rule = await this.ctx.service.pointsRule.getLevelRule(
				member.levelId,
			);
			const realPoints = this.ctx.service.pointsRule.applyTaskBonus(
				task.rewardPoints,
				rule,
			);

			// 写 completion log（已存在则更新）
			const [comp] = await (
				this.ctx.model.TaskCompletionLog as any
			).findOrCreate({
				where: { userTaskId: ut.id },
				defaults: {
					userTaskId: ut.id,
					userId,
					taskCode,
					cycleKey: ck,
					rewardPoints: realPoints,
					rewardGrowth: task.rewardGrowth,
					bonusRate: 1 + rule.taskBonusRate,
					status: 'pending',
				},
				transaction: t,
			});
			await comp.update(
				{
					rewardPoints: realPoints,
					rewardGrowth: task.rewardGrowth,
					bonusRate: 1 + rule.taskBonusRate,
				},
				{ transaction: t },
			);

			// 发积分
			const result = await this.ctx.service.member.addPoints(
				userId,
				realPoints,
				'task_reward',
				{
					event: 'task_reward',
					growthDelta: task.rewardGrowth,
					bizType: 'task',
					bizId: taskCode,
					remark: `任务奖励：${task.name}`,
					applyMultiplier: false,
					transaction: t,
				},
			);

			// 更新 completion log 与 user_task
			await comp.update(
				{ status: 'rewarded', pointsLogId: result.logId },
				{ transaction: t },
			);
			await ut.update(
				{ status: 'claimed', claimedAt: new Date() },
				{ transaction: t },
			);

			// 更新每日上限
			if (task.dailyCapGroup === 'task') {
				const today = new Date().toISOString().slice(0, 10);
				await (this.ctx.model.DailyPointsCap as any).upsert(
					{
						userId,
						capDate: today,
						capGroup: 'task',
						earned: this.app.Sequelize.literal(`earned + ${realPoints}`) as any,
					},
					{ transaction: t },
				);
			}

			return { points: realPoints, growth: task.rewardGrowth };
		});
	}

	/** 列出用户任务（按 category 过滤） */
	async listUserTasks(userId: number, filter: { category?: string } = {}) {
		const where: any = { status: 1 };
		if (filter.category) where.category = filter.category;
		const tasks: any[] = await this.ctx.model.Task.findAll({
			where,
			order: [['sort', 'ASC']],
		});

		const result: any[] = [];
		for (const task of tasks) {
			const ck = cycleKey(task.resetCycle);
			const ut: any = await this.ctx.model.UserTask.findOne({
				where: { userId, taskCode: task.code, cycleKey: ck },
			});
			result.push({
				code: task.code,
				name: task.name,
				icon: task.icon,
				description: task.description,
				category: task.category,
				progressTarget: task.progressTarget,
				rewardPoints: task.rewardPoints,
				rewardGrowth: task.rewardGrowth,
				progress: ut?.progress || 0,
				status: ut?.status || 'pending',
				expireAt: ut?.expireAt,
			});
		}
		return result;
	}

	/** 新手任务过期清理（schedule 调） */
	async expireNewbieTasks() {
		const { Op } = require('sequelize');
		const now = new Date();
		await this.ctx.model.UserTask.update(
			{ status: 'expired' },
			{ where: { status: 'pending', expireAt: { [Op.lt]: now } } },
		);
	}
}
```

```typescript
import { Subscription } from 'egg';

export default class TaskRewardResendSchedule extends Subscription {
	static get schedule() {
		return { interval: '5m', type: 'worker', immediate: false };
	}

	async subscribe() {
		const { ctx } = this;
		const { Op } = require('sequelize');

		const pendings: any[] = await ctx.model.TaskCompletionLog.findAll({
			where: {
				status: 'pending',
				retryCount: { [Op.lt]: 5 },
				[Op.or]: [
					{ nextRetryAt: null },
					{ nextRetryAt: { [Op.lte]: new Date() } },
				],
			},
			limit: 100,
		});

		for (const comp of pendings) {
			try {
				await ctx.model.transaction(async (t: any) => {
					const result = await ctx.service.member.addPoints(
						comp.userId,
						comp.rewardPoints,
						'task_reward',
						{
							event: 'task_reward',
							growthDelta: comp.rewardGrowth,
							bizType: 'task',
							bizId: comp.taskCode,
							remark: `任务奖励补发：${comp.taskCode}`,
							applyMultiplier: false,
							transaction: t,
						},
					);
					await comp.update(
						{ status: 'rewarded', pointsLogId: result.logId },
						{ transaction: t },
					);
				});
				ctx.logger.info(
					`[task_resend] ok user=${comp.userId} task=${comp.taskCode}`,
				);
			} catch (err: any) {
				const next = new Date(
					Date.now() + Math.pow(2, comp.retryCount + 1) * 60000,
				); // 指数退避
				await comp.update({
					retryCount: comp.retryCount + 1,
					nextRetryAt: next,
					errorMsg: err.message,
				});
				if (comp.retryCount + 1 >= 5) await comp.update({ status: 'failed' });
				ctx.logger.error(
					`[task_resend] retry user=${comp.userId} task=${comp.taskCode} err=${err.message}`,
				);
			}
		}
	}
}
```

```typescript
// app/service/pointsMall.ts
import BaseService from './base';

export default class PointsMallService extends BaseService {
	/** C端：商品列表 */
	async listItems(filter: { category?: string } = {}) {
		const { Op } = require('sequelize');
		const where: any = { status: 1 };
		if (filter.category) where.category = filter.category;
		const now = new Date();
		where[Op.and] = [
			{ [Op.or]: [{ validFrom: null }, { validFrom: { [Op.lte]: now } }] },
			{ [Op.or]: [{ validTo: null }, { validTo: { [Op.gte]: now } }] },
		];
		return await this.ctx.model.PointsMallItem.findAll({
			where,
			order: [['sort', 'ASC']],
		});
	}

	/** 兑换 */
	async exchange(
		userId: number,
		itemId: number,
		deliveryInfo?: {
			receiverName?: string;
			receiverPhone?: string;
			receiverAddress?: string;
		},
	) {
		return await this.ctx.model.transaction(async (t: any) => {
			// 1) 锁商品
			const item: any = await this.ctx.model.PointsMallItem.findOne({
				where: { id: itemId, status: 1 },
				lock: t.LOCK.UPDATE,
				transaction: t,
			});
			if (!item) throw new Error('商品不存在或已下架');

			// 2) 时间窗校验
			const now = new Date();
			if (item.validFrom && item.validFrom > now) throw new Error('商品未上架');
			if (item.validTo && item.validTo < now) throw new Error('商品已下架');

			// 3) 库存校验
			if (item.stock !== -1 && item.stock <= 0) throw new Error('库存不足');

			// 4) 用户余额/等级
			const member: any = await this.ctx.model.UserMember.findOne({
				where: { userId },
				lock: t.LOCK.UPDATE,
				transaction: t,
			});
			if (!member) throw new Error('用户会员记录不存在');
			if (member.points < item.costPoints) throw new Error('积分不足');
			if (item.requiredLevel) {
				const requiredLevel: any = await this.ctx.model.MemberLevel.findOne({
					where: { code: item.requiredLevel },
				});
				if (!requiredLevel || member.levelId < requiredLevel.id)
					throw new Error('等级不足');
			}

			// 5) 限购校验（每日 / 总）
			if (item.dailyLimit > 0) {
				const today = new Date();
				today.setHours(0, 0, 0, 0);
				const c = await this.ctx.model.PointsMallOrder.count({
					where: {
						userId,
						itemId,
						createdAt: { [require('sequelize').Op.gte]: today },
					},
					transaction: t,
				});
				if (c >= item.dailyLimit) throw new Error('已达每日限兑次数');
			}
			if (item.totalLimit > 0) {
				const c = await this.ctx.model.PointsMallOrder.count({
					where: { userId, itemId },
					transaction: t,
				});
				if (c >= item.totalLimit) throw new Error('已达总限兑次数');
			}

			// 6) 实物商品要求收货信息
			if (
				item.isVirtual === 0 &&
				(!deliveryInfo?.receiverName ||
					!deliveryInfo?.receiverPhone ||
					!deliveryInfo?.receiverAddress)
			) {
				throw new Error('实物商品需要填写收货信息');
			}

			// 7) 扣积分
			const cr = await this.ctx.service.member.consumePoints(
				userId,
				item.costPoints,
				'mall_exchange',
				{
					event: 'mall_exchange',
					bizType: 'mall',
					bizId: String(item.id),
					remark: `兑换：${item.name}`,
					transaction: t,
				},
			);

			// 8) 扣库存
			if (item.stock !== -1) {
				await item.update({ stock: item.stock - 1 }, { transaction: t });
			}

			// 9) 写订单（含快照）
			const orderNo = `PM${Date.now()}${Math.random().toString(36).slice(2, 8).toUpperCase()}`;
			const productSnapshot = {
				id: item.id,
				name: item.name,
				icon: item.icon,
				description: item.description,
				category: item.category,
				costPoints: item.costPoints,
				fulfillConfig: item.fulfillConfig,
				isVirtual: item.isVirtual,
			};
			const order: any = await this.ctx.model.PointsMallOrder.create(
				{
					orderNo,
					userId,
					itemId: item.id,
					costPoints: item.costPoints,
					productSnapshot,
					pointsLogId: cr.logId,
					fulfillStatus: 'pending',
					receiverName: deliveryInfo?.receiverName,
					receiverPhone: deliveryInfo?.receiverPhone,
					receiverAddress: deliveryInfo?.receiverAddress,
				},
				{ transaction: t },
			);

			// 10) 履约（虚拟商品立即；实物等管理员发货）
			if (item.isVirtual === 1) {
				const result = await this.fulfillVirtual(userId, productSnapshot, t);
				await order.update(
					{
						fulfillStatus: 'fulfilled',
						fulfillResult: result,
						fulfilledAt: new Date(),
					},
					{ transaction: t },
				);
			} else {
				await order.update({ fulfillStatus: 'shipping' }, { transaction: t });
			}

			// 11) 通知
			try {
				await (this.ctx.service.notification as any).core.send({
					typeCode: 'BUSINESS_MALL_FULFILLED',
					userId,
					variables: { itemName: item.name, orderNo },
				});
			} catch {
				/* ignore */
			}

			return {
				orderNo,
				fulfillStatus: order.fulfillStatus,
				balance: cr.balance,
			};
		});
	}

	/** 虚拟商品履约 */
	private async fulfillVirtual(
		userId: number,
		snap: any,
		t: any,
	): Promise<any> {
		const cfg = snap.fulfillConfig;
		switch (cfg.type) {
			case 'member_days': {
				// 给用户加 N 天 paid 会员（或延长现有）
				const member: any = await this.ctx.model.UserMember.findOne({
					where: { userId },
					lock: t.LOCK.UPDATE,
					transaction: t,
				});
				const base =
					member.paidExpireAt && member.paidExpireAt > new Date()
						? member.paidExpireAt
						: new Date();
				const newExpire = new Date(base.getTime() + cfg.days * 86400000);
				await member.update(
					{
						isPaid: 1,
						paidPlanCode: cfg.plan_code,
						paidStartAt: member.paidStartAt || new Date(),
						paidExpireAt: newExpire,
					},
					{ transaction: t },
				);
				return { type: 'member_days', expireAt: newExpire };
			}
			case 'coupon': {
				// 真实生成优惠券（如有 coupons 表则插入；MVP 暂记录到 fulfillResult）
				return { type: 'coupon', couponCode: `CP${Date.now()}`, ...cfg };
			}
			case 'tool_unlock': {

				orderId,

			if (order.refundStatus !== 'none')

				order.productSnapshot.isVirtual === 1
			) {

			await this.ctx.service.member.refundPoints(
				order.userId,
				order.pointsLogId,
				order.costPoints,

					remark: `商城订单退款：${order.orderNo} - ${reason}`,
					transaction: t,

				order.itemId,

			);

				{
					refundStatus: 'refunded',
					refundReason: reason,
					refundedAt: new Date(),
					fulfillStatus: 'refunded',
				},
				{ transaction: t },
			);

			return { orderNo: order.orderNo, refundedPoints: order.costPoints };
		});
```

```typescript
		let totalExpired = 0;

		while (true) {
			const batches: any[] = await this.ctx.model.PointsLog.findAll({

					['expire_at', 'ASC'],
					['id', 'ASC'],
				],
			});
			if (batches.length === 0) break;

			for (const b of batches) {
				const expired = b.pointsRemaining;
				await this.ctx.model.transaction(async (t: any) => {
					// 幂等：先看是否已处理

						where: { sourceLogId: b.id },
						transaction: t,

					await b.reload({ lock: t.LOCK.UPDATE, transaction: t });

						transaction: t,
					});

					await member.update({ points: newBalance }, { transaction: t });

						{
							userId: b.userId,
							type: 3,

				/* ignore */
			}
		}

			{ days: 30, stage: 1, channels: ['inbox', 'push'] },
			{ days: 7, stage: 2, channels: ['sms', 'push'] },

			});
```

```typescript
// app/service/pointsReconcile.ts
import BaseService from './base';

export default class PointsReconcileService extends BaseService {
	/** 日终全量快照（每日 23:55） */
	async takeDailySnapshot(): Promise<{ users: number; anomalies: number }> {
		const { Op, fn, col, literal } = require('sequelize');
		const today = new Date();
		today.setHours(0, 0, 0, 0);
		const todayStr = today.toISOString().slice(0, 10);

		// 分批：每次 1000 用户
		let offset = 0;
		let users = 0;
		let anomalies = 0;

		while (true) {
			const members: any[] = await this.ctx.model.UserMember.findAll({
				attributes: ['userId', 'points', 'growthValue', 'levelId'],
				order: [['user_id', 'ASC']],
				limit: 1000,
				offset,
			});
			if (members.length === 0) break;

			for (const m of members) {
				// 计算理论值：sum(type=1 points) + sum(type 2/3/4 points)
				const sumRow: any = await this.ctx.model.PointsLog.findOne({
					attributes: [[fn('SUM', col('points')), 'total']],
					where: { userId: m.userId },
					raw: true,
				});
				const theoretical = Number(sumRow?.total) || 0;
				const diff = m.points - Math.max(0, theoretical);
				const isAnomaly = Math.abs(diff) > 0;
				if (isAnomaly) anomalies++;

				await (this.ctx.model.PointsDailySnapshot as any).upsert({
					snapshotDate: todayStr,
					userId: m.userId,
					pointsBalance: m.points,
					theoreticalBalance: theoretical,
					diff,
					growthValue: m.growthValue,
					levelId: m.levelId,
					isAnomaly: isAnomaly ? 1 : 0,
				});
				users++;
			}
			offset += 1000;
		}
		return { users, anomalies };
	}

	/** 每小时巡检（采样最近变动 100 用户） */
	async hourlyBalanceCheck(): Promise<{ checked: number; anomalies: any[] }> {
		const { Op, fn, col } = require('sequelize');
		const since = new Date(Date.now() - 60 * 60 * 1000);

		// 找最近 1 小时有 points_logs 写入的用户
		const recent: any[] = await this.ctx.model.PointsLog.findAll({
			attributes: [[fn('DISTINCT', col('user_id')), 'userId']],
			where: { createdAt: { [Op.gte]: since } },
			limit: 100,
			raw: true,
		});

		const anomalies: any[] = [];
		for (const r of recent) {
			const userId = (r as any).userId;
			const m: any = await this.ctx.model.UserMember.findOne({
				where: { userId },
			});
			if (!m) continue;
			const sumRow: any = await this.ctx.model.PointsLog.findOne({
				attributes: [[fn('SUM', col('points')), 'total']],
				where: { userId },
				raw: true,
			});
			const theoretical = Math.max(0, Number(sumRow?.total) || 0);
			const diff = m.points - theoretical;
			if (Math.abs(diff) > 0) {
				anomalies.push({ userId, actual: m.points, theoretical, diff });
			}
		}

		if (anomalies.length > 0) {
			this.ctx.logger.error(
				`[reconcile] anomalies=${anomalies.length} sample=${JSON.stringify(anomalies.slice(0, 3))}`,
			);
			// 触发告警（如有 alert_logs 模块）
			try {
				await (this.ctx.service.alert as any)?.createLog?.({
					ruleCode: 'points_balance_anomaly',
					severity: 'warning',
					message: `积分余额异常 ${anomalies.length} 个用户`,
					payload: { anomalies: anomalies.slice(0, 10) },
				});
			} catch {
				/* ignore */
			}
		}

		return { checked: recent.length, anomalies };
	}

	/** 管理端：查询某日快照 */
	async listSnapshots(query: {
		date?: string;
		onlyAnomaly?: boolean;
		page?: number;
		pageSize?: number;
	}) {
		const date = query.date || new Date().toISOString().slice(0, 10);
		const where: any = { snapshotDate: date };
		if (query.onlyAnomaly) where.isAnomaly = 1;
		const page = query.page || 1;
		const pageSize = query.pageSize || 50;
		return await this.ctx.model.PointsDailySnapshot.findAndCountAll({
			where,
			order: [['diff', 'DESC']],
			limit: pageSize,
			offset: (page - 1) * pageSize,
		});
	}
}
```

**设计：**

- 客户端在 POST 请求头带 `Idempotency-Key: <UUIDv4>`
- 服务端 Redis 写 `idem:{userId}:{key}`，TTL 24h，值为首次响应的 JSON
- 同 Key 第二次请求直接返回首次响应
- 仅对"积分写入类"路由启用：claim / exchange / signin

- [ ] **Step 1: 创建中间件**

```typescript
// app/middleware/idempotency.ts
import { Context } from 'egg';

export default function idempotency(options: { ttlHours?: number } = {}) {
	const ttl = (options.ttlHours || 24) * 3600;
	return async (ctx: Context, next: () => Promise<any>) => {
		const key = ctx.get('idempotency-key');
		const userId = (ctx.state.user || (ctx as any).user)?.id;

		// 没有 key 或非登录请求，跳过
		if (!key || !userId) return await next();

		// 校验 UUIDv4 格式
		if (
			!/^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i.test(
				key,
			)
		) {
			ctx.status = 400;
			ctx.body = {
				code: 400,
				message: 'Invalid Idempotency-Key (expect UUID v4)',
			};
			return;
		}

		const redisKey = `idem:${userId}:${key}`;
		const redis = (ctx.app as any).redis;
		if (!redis) return await next();

		const cached = await redis.get(redisKey);
		if (cached) {
			const obj = JSON.parse(cached);
			ctx.status = obj.status || 200;
			ctx.body = obj.body;
			ctx.set('x-idempotent-replayed', 'true');
			return;
		}

		await next();

		// 仅成功响应缓存（2xx）
		if (ctx.status >= 200 && ctx.status < 300) {
			await redis.setex(
				redisKey,
				ttl,
				JSON.stringify({ status: ctx.status, body: ctx.body }),
			);
		}
	};
}
```

```typescript
		const r = await ctx.service.pointsReconcile.listSnapshots({
			date: ctx.query.date as string,
			onlyAnomaly: ctx.query.onlyAnomaly === 'true',
			page: Number(ctx.query.page) || 1,
			pageSize: Number(ctx.query.pageSize) || 50,
		});
		this.success({ list: (r as any).rows, total: (r as any).count });
	}

	/** POST /api/admin/points/ops/trigger  body: { task: 'expire'|'remind'|'snapshot'|'check' } */
	async trigger() {
		const { ctx } = this;
		const task = ctx.request.body.task;
		let r: any;
		switch (task) {
			case 'expire':
				r = await ctx.service.pointsExpire.processExpiredBatches();
				break;
			case 'remind':
				r = await ctx.service.pointsExpire.sendExpireReminders();
				break;
			case 'snapshot':
				r = await ctx.service.pointsReconcile.takeDailySnapshot();
				break;
			case 'check':
				r = await ctx.service.pointsReconcile.hourlyBalanceCheck();
				break;
			default:
				ctx.throw(400, 'task 必须是 expire/remind/snapshot/check 之一');
		}
		this.success({ task, result: r });
	}
```
