## 1. 概述

### 1.1 目标

在 Phase 1 已完成的 MVP（订单 + Mock 支付 + 通知 + admin 只读）基础上，补齐 4 个独立但相互关联的能力，使整个会员订阅子系统达到生产就绪：

1. **A. 支付宝沙箱接入**：从 Mock 支付升级为真实支付通道；H5 收银台支持 Alipay；服务端验签 + 状态主动 query；可选 Webhook
2. **B. 退款流程**：admin 端发起全额退款；调通道 API 同步处理；会员立即失效；通知 + audit
3. **C. 订阅升降级**：用户可在已付费状态下切换套餐（双向）；价格按"剩余价值折算法"计算；升级走差价订单，降级走 0 元订单
4. **D. 遗留补齐**：管理端 schedule 测试触发器、orderExpireCheck 单测、支付失败重试、退款 audit 埋点

### 2.2 关键数据流

#### 2.2.1 Alipay 沙箱支付

```
1. 用户在 H5 cashier 选 alipay → POST /api/payments {orderId, provider:'alipay'}
2. PaymentService.create 调 AlipayProvider.createPrepay
   → SDK pageExec('alipay.trade.wap.pay', bizContent={out_trade_no, total_amount, subject})
   → 返回带签名的 GET URL
3. 后端写 member_payments(status=0, prepayData={url})，返回 cashierUrl 给前端
4. 前端 location.href = cashierUrl → 跳沙箱网关
5. 用户登录沙箱买家账号 → 支付
6. Alipay 回调链路（双轨）：
   ① 同步 return_url：GET /api/payments/alipay/return → 后端 302 redirect 到 H5 /member/orders/:id
   ② 异步 notify_url（可选）：POST /api/payments/alipay/notify
      → AlipayProvider.verifyCallback 验签 → service.payment.handleCallback → 走标准流程
7. 同时：H5 订单详情/收银台轮询 GET /api/payments/:no/status
   → service.payment.getStatus 检测 status=0 + age≥5s → AlipayProvider.queryStatus
   → 主动 query 拉到 success → 调 _applyPaymentSuccess（与 handleCallback 共享）
   → 前端拿到 status=1 跳订单详情
```

#### 2.2.2 退款

```
admin 订单详情抽屉 → 点"全额退款" → 输入 reason → 二次确认
  │
  │ POST /api/admin/member/orders/:id/refund {reason}
  ▼
RefundService.create (单事务)
  ├ 行级锁 SELECT order
  ├ 校验：order.status===1 且无现存 refund 处理中/成功
  ├ 找原 payment.status===1（行级锁）
  ├ INSERT member_refunds(status=0)
  ├ AlipayProvider.refund({paymentNo, refundNo, amount, reason})
  │   → SDK exec('alipay.trade.refund')
  │   → 同步返回 fund_change=Y/N
  ├ 成功路径：
  │   - UPDATE member_refunds(status=1, providerRefundNo, refundedAt)
  │   - UPDATE member_payments(status=3 已退款)
  │   - UPDATE member_orders(status=4 已退款)
  │   - UPDATE user_members(is_paid=0, paid_expire_at=NOW)
  │   - 事务外 ctx.runInBackground:
  │     · notification.core.send BUSINESS_PAYMENT_REFUNDED
  │     · audit.log refund.success
  └ 失败路径：UPDATE member_refunds(status=2,failedReason) + throw 让事务 rollback
```

#### 2.2.3 升降级

```
H5 /member 看到当前付费会员 + 其他套餐卡片不再禁用
  ↓ 用户点"切换到年度"
  POST /api/orders {planCode:'yearly'}
  ↓
OrderService.create
  ├ 拉 newPlan（PaidPlan）
  ├ 拉 currentMember（UserMember）+ currentPlan（如付费中）
  ├ priceCalculator.calcSwitchPlan(currentMember, currentPlan, newPlan)
  │   → 输出 {scene, amount, remainingValue, newExpireAt, reason}
  │     · 未付费/已过期 → scene=1 (新购)，amount=newPlan.price
  │     · 同套餐 → scene=2 (续费)，amount=newPlan.price
  │     · 不同 + new>剩余值 → scene=3 (升级)，amount=差价
  │     · 不同 + new≤剩余值 → scene=4 (降级)，amount=0
  ├ 防重复未支付订单（保留 phase1 校验）
  ├ INSERT member_orders(...,scene,sourcePlanCode,sourceRemainingValue)
  ├ scene=4 立即:
  │   - status=1, paidAt=NOW
  │   - member.activatePaidPlan(mode='downgrade', newExpireAt=NOW + daysFromValue)
  │   - 订单返回直接告诉前端 scene=4 无需支付
  └ 其他场景照旧返回 orderId 让前端跳收银台
```

### 2.3 设计原则

- **Provider 接口稳定性**：`PaymentProvider` 本轮新增 `refund()`，三个 Provider 全部更新；后续接微信真实支付不再改接口
- **订单 scene 单调扩展**：1 新购 / 2 续费 / 3 升级 / 4 降级（amount=0 特殊订单）
- **审计统一通道**：所有写操作（退款）走 `service.audit.log`，与 C2a/C2b 规范一致
- **失败可观测**：所有 alipay 调用 try/catch，失败时把 alipay 返回值写入 audit detail 字段
- **配置三层**：`system_configs`（公开） + `.env.local`（密钥） + `app/config/config.default.ts`（默认）
- **无状态主动 query**：getStatus 检测 status=0 且 age≥5s 主动查通道（防 webhook 丢失），但仅 alipay/wechat（mock 跳过）
- **降级无退款**：降级走 0 元订单 + 剩余价值折算天数，避免与 B 退款流程语义冲突

#### 4.3.2 `app/lib/payment/alipay.ts`（新增）

完整类实装，关键方法签名（详细代码见 plan）：

```typescript
import { AlipaySdk } from 'alipay-sdk';

export interface AlipayConfig {
  appId: string;
  privateKey: string;
  alipayPublicKey: string;
  gateway: string;
  signType?: 'RSA2' | 'RSA';
  notifyUrl?: string;
  returnUrl?: string;
}

export class AlipayProvider implements PaymentProvider {
  private sdk: AlipaySdk;
  private cfg: AlipayConfig;

  constructor(cfg: AlipayConfig) {
    if (!cfg.appId || !cfg.privateKey || !cfg.alipayPublicKey) {
      throw new Error('AlipayProvider 缺少必要配置');
    }
    this.cfg = cfg;
    this.sdk = new AlipaySdk({
      appId: cfg.appId,
      privateKey: cfg.privateKey,
      alipayPublicKey: cfg.alipayPublicKey,
      gateway: cfg.gateway,
      signType: cfg.signType || 'RSA2',
      timeout: 10000,
      camelcase: true,
    });
  }

  /** 创建支付：调 alipay.trade.wap.pay 拿跳转 URL */
  async createPrepay(input: CreatePrepayInput): Promise<CreatePrepayOutput> {
    const bizContent = {
      out_trade_no: input.paymentNo,
      total_amount: Number(input.amount).toFixed(2),
      subject: input.subject || `${input.planName || '会员'} 订阅`,
      product_code: 'QUICK_WAP_WAY',
      timeout_express: '30m',
    };
    const url = this.sdk.pageExec('alipay.trade.wap.pay', {
      bizContent,
      method: 'GET',
      notifyUrl: this.cfg.notifyUrl,
      returnUrl: this.cfg.returnUrl,
    });
    return {
      provider: 'alipay',
      prepayData: { url, bizContent },
      cashierUrl: url,
    };
  }

  /** 异步通知验签：rawBody 为 application/x-www-form-urlencoded */
  async verifyCallback(_headers, rawBody): Promise<VerifyCallbackOutput> {
    const params: Record<string, string> = {};
    new URLSearchParams(rawBody).forEach((v, k) => { params[k] = v; });
    const signOk = this.sdk.checkNotifySignV2(params);
    if (!signOk) return { valid: false, reason: 'signature mismatch' };
    if (params.trade_status !== 'TRADE_SUCCESS' && params.trade_status !== 'TRADE_FINISHED') {
      return { valid: false, reason: `bad trade_status: ${params.trade_status}` };
    }
    return {
      valid: true,
      paymentNo: params.out_trade_no,
      providerTradeNo: params.trade_no,
      amount: Number(params.total_amount),
      raw: params,
    };
  }

  /** 主动查询：alipay.trade.query */
  async queryStatus(paymentNo: string): Promise<QueryStatusOutput> {
    const res: any = await this.sdk.exec('alipay.trade.query', {
      bizContent: { out_trade_no: paymentNo },
    });
    if (res?.code !== '10000') return { status: 'unknown', raw: res };
    let status: 'success'|'pending'|'failed'|'unknown' = 'unknown';
    if (res.tradeStatus === 'TRADE_SUCCESS' || res.tradeStatus === 'TRADE_FINISHED') status = 'success';
    else if (res.tradeStatus === 'WAIT_BUYER_PAY') status = 'pending';
    else if (res.tradeStatus === 'TRADE_CLOSED') status = 'failed';
    return {
      status,
      providerTradeNo: res.tradeNo,
      amount: res.totalAmount ? Number(res.totalAmount) : undefined,
      raw: res,
    };
  }

  /** 退款：alipay.trade.refund */
  async refund(input: RefundInput): Promise<RefundResult> {
    const res: any = await this.sdk.exec('alipay.trade.refund', {
      bizContent: {
        out_trade_no: input.paymentNo,
        refund_amount: input.amount.toFixed(2),
        out_request_no: input.refundNo,
        refund_reason: input.reason || '用户申请退款',
      },
    });
    if (res?.code !== '10000') {
      return {
        success: false,
        fundChange: false,
        rawResponse: res,
        failedReason: res?.subMsg || res?.msg || 'alipay refund failed',
      };
    }
    return {
      success: true,
      providerRefundNo: res.tradeNo,
      fundChange: res.fundChange === 'Y',
      rawResponse: res,
    };
  }
}
```

### 4.4 PriceCalculator（升降级核心）

#### 4.4.1 新增 `app/lib/payment/priceCalculator.ts`

```typescript
/**
 * 升降级价格计算器（Q10=A 剩余价值折算法）
 *
 * 核心公式：
 *   remainingValue = currentPlan.price * (remainingDays / currentPlan.durationDays)
 *
 * 升级 (newPlan.price > remainingValue):
 *   scene = 3, amount = newPlan.price - remainingValue
 *   newExpireAt = NOW + newPlan.durationDays
 *
 * 降级 (newPlan.price <= remainingValue):
 *   scene = 4, amount = 0
 *   daysFromValue = floor((remainingValue / newPlan.price) * newPlan.durationDays)
 *   newExpireAt = NOW + daysFromValue
 */

export interface PlanInfo {
  code: string;
  price: number;          // 元
  durationDays: number;   // 0 = 永久（不参与升降级）
}

export interface MemberSnapshot {
  paidPlanCode?: string | null;
  paidExpireAt?: Date | string | null;
}

export interface SwitchCalcResult {
  scene: 1 | 2 | 3 | 4;
  amount: number;
  remainingDays: number;
  remainingValue: number;
  newExpireAt: Date;
  reason: string;
}

export function calcSwitchPlan(opts: {
  currentMember: MemberSnapshot;
  currentPlan?: PlanInfo;
  newPlan: PlanInfo;
  now?: Date;
}): SwitchCalcResult {
  const now = opts.now || new Date();
  const { currentMember, currentPlan, newPlan } = opts;

  // 场景 1：未付费
  const isPaid = !!(currentMember.paidPlanCode
    && currentMember.paidExpireAt
    && new Date(currentMember.paidExpireAt) > now);
  if (!isPaid) {
    return {
      scene: 1, amount: newPlan.price,
      remainingDays: 0, remainingValue: 0,
      newExpireAt: addDays(now, newPlan.durationDays),
      reason: '新购',
    };
  }

  // 场景 2：同套餐续费
  if (currentMember.paidPlanCode === newPlan.code) {
    return {
      scene: 2, amount: newPlan.price,
      remainingDays: diffDays(new Date(currentMember.paidExpireAt!), now),
      remainingValue: 0,
      newExpireAt: addDays(new Date(currentMember.paidExpireAt!), newPlan.durationDays),
      reason: '续费（叠加剩余天数）',
    };
  }

  // 场景 3 / 4：跨套餐
  if (!currentPlan || currentPlan.durationDays === 0) {
    throw new Error('当前套餐为永久或不可识别，不支持升降级');
  }
  const remainingDays = diffDays(new Date(currentMember.paidExpireAt!), now);
  const remainingValue = round2(currentPlan.price * (remainingDays / currentPlan.durationDays));

  if (newPlan.price > remainingValue) {
    return {
      scene: 3,
      amount: round2(newPlan.price - remainingValue),
      remainingDays, remainingValue,
      newExpireAt: addDays(now, newPlan.durationDays),
      reason: `升级（差价 = ${newPlan.price.toFixed(2)} - ${remainingValue.toFixed(2)}）`,
    };
  }
  const daysFromValue = Math.floor((remainingValue / newPlan.price) * newPlan.durationDays);
  return {
    scene: 4, amount: 0,
    remainingDays, remainingValue,
    newExpireAt: addDays(now, daysFromValue),
    reason: `降级（剩余价值 ${remainingValue.toFixed(2)} 折算 ${daysFromValue} 天）`,
  };
}

function diffDays(future: Date, base: Date): number {
  const diff = (future.getTime() - base.getTime()) / 86400000;
  return Math.max(0, Math.ceil(diff));
}
function addDays(d: Date, days: number): Date {
  const r = new Date(d); r.setDate(r.getDate() + days); return r;
}
function round2(n: number): number { return Math.round(n * 100) / 100; }
```

```typescript
async create(input: CreateOrderInput) {
```

```typescript
async activatePaidPlan(userId: number, planCode: string, extra?: {
  orderId?: number;
  mode?: 'new' | 'renew' | 'upgrade' | 'downgrade';
  newExpireAt?: Date;
}) {
  const mode = extra?.mode || 'new';
  const plan = await this.ctx.model.PaidPlan.findOne({ where: { code: planCode } });
  if (!plan) throw new Error(`PaidPlan ${planCode} not found`);
  const planData = (plan as any).toJSON();

  let baseDate: Date;
  if (mode === 'upgrade' || mode === 'downgrade') {
    if (!extra?.newExpireAt) throw new Error(`${mode} 必须传 newExpireAt`);
    baseDate = extra.newExpireAt;
  } else if (mode === 'renew') {
    const cur = await this.ctx.model.UserMember.findOne({ where: { userId } });
    const curExpire = cur && (cur as any).toJSON().paidExpireAt;
    const startBase = curExpire && new Date(curExpire) > new Date() ? new Date(curExpire) : new Date();
    baseDate = new Date(startBase.getTime() + planData.durationDays * 86400000);
  } else { // new
    baseDate = new Date(Date.now() + planData.durationDays * 86400000);
  }

  await this.ctx.model.UserMember.upsert({
    userId, isPaid: 1,
    paidPlanCode: planCode,
    paidStartAt: new Date(),
    paidExpireAt: baseDate,
    levelExpireAt: baseDate,
  });

  // 通知 + 积分（保持 Phase 1 行为，事务外）
  this.ctx.runInBackground(async () => {
    try {
      await (this.ctx.service.notification as any).core.send({
        typeCode: 'BUSINESS_PLAN_ACTIVATED',
        userId,
        variables: {
          planName: planData.name,
          expireAt: baseDate.toISOString().slice(0, 10),
          mode,
        },
        idempotentKey: `plan_activate_${userId}_${extra?.orderId || Date.now()}`,
      });
    } catch (e: any) {
      this.ctx.logger.warn(`[activatePaidPlan] notify fail: ${e.message}`);
    }
    if (planData.giftPoints && planData.giftPoints > 0) {
      try {
        await (this.ctx.service.member as any).addPoints(userId, planData.giftPoints, planData.giftGrowth || 0, {
          source: 'plan',
          bizType: 'order',
          bizId: String(extra?.orderId || ''),
          remark: `订阅 ${planData.name} 赠送`,
        });
      } catch (e: any) {
        this.ctx.logger.warn(`[activatePaidPlan] addPoints fail: ${e.message}`);
      }
    }
  });
}
```

> **NOW 基准说明（重要）**：
> - **order.create 时**：scene=4 降级走 0 元订单，立即开通，此时 `calc.newExpireAt` 用 order.create 的 NOW 即可（误差秒级，可忽略）
> - **handleCallback 时**（scene=3 升级 + 真实支付）：用户从下单到支付成功可能间隔 5-30 分钟。统一规则——**以支付成功时刻（handleCallback 触发时）为新 expireAt 起点**重新计算。这也是行业惯例（用户感受：从我付款这一刻起年度生效）
> - **scene=2 续费**：activatePaidPlan 内部用 `max(curExpireAt, NOW) + duration` 公式，自然处理时差

```typescript
async getStatus(paymentNo, userId) {
  let payment = await this.ctx.model.MemberPayment.findOne({ where: { paymentNo, userId }});
  if (!payment) this.ctx.throw(404, '支付流水不存在');
  let data = (payment as any).toJSON();

  // 主动 query 兜底（status=0 + 非 mock + 创建后 ≥5 秒）
  const ageSeconds = (Date.now() - new Date(data.createdAt).getTime()) / 1000;
  if (data.status === 0 && data.provider !== 'mock' && ageSeconds >= 5) {
    try {
      const provider = createProvider(data.provider, this.ctx);
      const q = await provider.queryStatus(data.paymentNo);
      if (q.status === 'success') {
        await this._applyPaymentSuccess(payment, q.providerTradeNo!);
        const fresh = await this.ctx.model.MemberPayment.findOne({ where: { paymentNo }});
        data = (fresh as any).toJSON();
      } else if (q.status === 'failed') {
        await this.markFailed(paymentNo, '通道返回 TRADE_CLOSED');
        const fresh = await this.ctx.model.MemberPayment.findOne({ where: { paymentNo }});
        data = (fresh as any).toJSON();
      }
    } catch (e: any) {
      this.ctx.logger.warn(`[getStatus] active query fail: ${e.message}`);
    }
  }

  return { id: data.id, paymentNo: data.paymentNo, orderId: data.orderId,
    provider: data.provider, providerTradeNo: data.providerTradeNo,
    amount: data.amount, status: data.status, paidAt: data.paidAt,
    failedReason: data.failedReason, createdAt: data.createdAt };
}

private async _applyPaymentSuccess(payment, providerTradeNo: string) {
  // 行级锁 + 事务（与 handleCallback 内层逻辑共享）
  await this.ctx.model.transaction(async (t) => {
    const p = await this.ctx.model.MemberPayment.findOne({
      where: { id: (payment as any).id }, lock: t.LOCK.UPDATE, transaction: t,
    });
    if ((p as any).status === 1) return; // 幂等
    await (p as any).update({ status: 1, providerTradeNo, paidAt: new Date() }, { transaction: t });

    const order = await this.ctx.model.MemberOrder.findOne({
      where: { id: (p as any).orderId }, lock: t.LOCK.UPDATE, transaction: t,
    });
    await (order as any).update({ status: 1, paidAt: new Date() }, { transaction: t });
  });

  // 事务外开通会员
  const orderFresh = await this.ctx.model.MemberOrder.findOne({ where: { id: (payment as any).orderId }});
  const od: any = (orderFresh as any).toJSON();
  const mode = od.scene === 3 ? 'upgrade' : od.scene === 2 ? 'renew' : 'new';
  let newExpireAt;
  if (mode === 'upgrade') {
    const plan = await this.ctx.model.PaidPlan.findOne({ where: { code: od.planCode }});
    newExpireAt = new Date(Date.now() + (plan as any).durationDays * 86400000);
  }
  await this.service.member.activatePaidPlan(od.userId, od.planCode, {
    orderId: od.id, mode, newExpireAt,
  });
}
```

## 9. 风险与边界

### 9.1 技术风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| alipay-sdk v3 API 变更 | 中 | 锁版本 `^4.x` 稳定版；用 `pageExec`/`exec` 公开 API |
| 异步通知签名验证失败 | 高 | 沙箱用支付宝公钥（不是 RSA Key）；文档明确"应用公钥 vs 支付宝公钥"区别 |
| 主动 query 与 webhook 双发导致重复处理 | 高 | `_applyPaymentSuccess` 用行级锁 + `if (status===1) return` 幂等 |
| 升级回调时 NOW 与 order 创建时 NOW 偏差 | 低 | 文档明确：升级 newExpireAt 以"支付成功时"为基准（更公平） |
| 降级 daysFromValue=0（剩余价值<新套餐单日价）| 低 | floor 保证 ≥0；文档建议管理端 plan 配置时单日价合理 |
| 退款时同时 admin 多人操作 | 中 | RefundService 行级锁 order + 事务 + UNIQUE refund_no |
| Alipay 退款失败但 H5 已显示成功 | 中 | 退款成功只在事务 commit 后写 audit；事务内任何 throw 都 rollback；前端拿到错误码立即 message.error |
| 永久会员（durationDays=0）尝试升降级 | 低 | calcSwitchPlan throw + controller 返回 400 + 前端 modal 提示"永久会员不支持切换" |
| .env.local 私钥泄漏 | 高 | `.gitignore` + 文档红字警告 + git pre-commit hook（推荐）扫密钥 |

### 9.2 业务边界

| 场景 | 处理 |
|---|---|
| 升级订单未支付时 admin 发起退款 | 拦截：仅 status=1 可退 |
| 降级 0 元订单（status 直接 1）申请退款 | 允许，但 amount=0；Provider.refund 应识别 0 元并直接返回成功 |
| 用户已升级到年度，又要降级回月度 | 允许（双向支持）；按剩余价值折算 |
| 退款后用户再次下单（任意套餐） | 允许，scene=1 新购 |
| 升级订单的差价低于通道最小金额（alipay ≥0.01） | 校验 amount ≥ 0.01；< 0.01 时按降级 0 元处理（floor） |
| 沙箱买家账号余额不足 | 沙箱网关返回失败 → 用户跳回订单详情看到 status=0；可重试 |

## 10. 不变量保证

| 不变量 | 由谁保证 |
|---|---|
| 同 paymentNo 不会被处理两次 | `_applyPaymentSuccess` 行级锁 + status===1 跳过 |
| 同 orderId 不会有 2 个 status=success 的 payment | PaymentService.create 校验 |
| 同 orderId 不会有 2 个 status∈{0,1} 的 refund | RefundService.create 校验 |
| 退款成功后会员立即失效 | 单事务内 update user_members |
| 升级金额始终 = newPlan.price - oldRemainingValue | calcSwitchPlan 严格按公式 |
| scene=4 amount 始终 = 0 | calcSwitchPlan 强制 |
| order.scene 与 scene 路径一一对应 | order.create 唯一写入点 |
