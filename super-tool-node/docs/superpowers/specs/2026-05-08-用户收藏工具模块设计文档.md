## 一、需求概览

### 1.1 背景

在已上线的**工具管理模块**（`tool_categories` / `tools`）基础上，产品希望加入个性化的**收藏能力**，提升工具发现与复用效率：

1. 工具列表页可一键**收藏**任意上架工具（心形高亮）
2. 登录用户拥有**个人收藏中心**：
   - 展示历史收藏列表
   - 支持**拖拽手动排序**
   - 支持**按名称/描述/关键词搜索**
   - 支持**取消收藏**

### 1.2 范围

| IN（本期实现） | OUT（后续迭代） |
|---------------|----------------|
| 收藏 / 取消收藏 | 收藏夹分组 / 多收藏夹 |
| 个人收藏列表 + 分页 + 搜索 | 收藏次数排行 |
| 手动拖拽排序 | 协同/分享收藏夹 |
| 工具列表页批量标注收藏态 | 收藏通知（工具更新提醒） |
| 单工具收藏态查询 | 收藏数据导出 |

### 1.3 设计原则

- **鉴权**：所有接口必须登录
- **数据隔离**：严格按 `user_id` 分片，用户仅能访问自己的收藏
- **幂等**：重复收藏返回 409，语义明确，不创建重复记录
- **防篡改**：取消收藏 / 排序接口不接受他人 `userId` 参数，以 JWT 中的用户身份为准

## 三、数据库详细设计

### 3.1 `user_tool_favorites` 表

| 字段 | 类型 | 空 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT UNSIGNED | NOT NULL | AUTO_INCREMENT | 主键 |
| `user_id` | BIGINT UNSIGNED | NOT NULL | — | 用户ID |
| `tool_id` | BIGINT UNSIGNED | NOT NULL | — | 工具ID |
| `tool_code` | VARCHAR(60) | NOT NULL | — | 工具编码（冗余） |
| `sort` | INT | NOT NULL | 0 | 手动排序（越小越前） |
| `favorited_at` | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 收藏时间 |
| `created_at` | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引：**
- `PRIMARY KEY (id)`
- `UNIQUE KEY uk_user_tool (user_id, tool_id)` — 防止重复收藏
- `INDEX idx_user_sort (user_id, sort, id)` — 支撑列表查询
- `INDEX idx_user_favorited (user_id, favorited_at)` — 兜底排序
- `INDEX idx_tool (tool_id)` — 外键
- `INDEX idx_tool_code (tool_code)` — 轻量 code 查询

**外键：**
- `fk_favorite_user`: `user_id` → `users.id` (CASCADE)
- `fk_favorite_tool`: `tool_id` → `tools.id` (CASCADE)

**迁移脚本：** `database/005_add_user_favorites.sql` (v2.4.0)

### 3.2 为什么冗余 `tool_code`

- `GET /api/favorites/codes` 和 `DELETE /api/favorites/:toolCode` 两个接口只需 code 即可完成业务，**避免额外 JOIN**
- 对 `user_id + tool_code` 查询命中率高
- 由 Service 层写入时同步从 Tool 表读取并写入，保证一致性（外键 CASCADE 兜底避免悬挂）

## 四、API 接口设计

### 4.1 接口清单

| # | 方法 | 路径 | 鉴权 | 说明 |
|---|------|------|------|------|
| 1 | POST | `/api/favorites` | ✅ | 收藏工具 |
| 2 | DELETE | `/api/favorites/:toolCode` | ✅ | 取消收藏 |
| 3 | GET | `/api/favorites` | ✅ | 分页列表（支持搜索/分类） |
| 4 | GET | `/api/favorites/codes` | ✅ | 轻量 code 集合 |
| 5 | GET | `/api/favorites/check/:toolCode` | ✅ | 单工具收藏态 |
| 6 | PUT | `/api/favorites/reorder` | ✅ | 手动拖拽排序 |

详细字段、响应结构参见：[API 文档 `docs/api/favorite/README.md`](../../api/favorite/README.md)

### 4.2 路由顺序注意事项

由于 Egg.js/Koa 的路由匹配基于声明顺序，**精确路径必须在 `:toolCode` 通配前声明**：

```ts
router.get('/api/favorites/codes', ...);            // 精确
router.put('/api/favorites/reorder', ...);          // 精确
router.get('/api/favorites/check/:toolCode', ...);  // 子路径精确
router.get('/api/favorites', ...);
router.post('/api/favorites', ...);
router.delete('/api/favorites/:toolCode', ...);     // 通配放最后
```

## 五、Service 层核心逻辑

### 5.1 新增收藏（addFavorite）

```
1. 校验入参：toolId 或 toolCode 至少一个
2. resolveTool: 按 (status=1) AND (id=toolId | code=toolCode) 查工具
   - 不存在 → 404
3. 查询 uk_user_tool 是否已存在 → 409
4. 计算新 sort = max(user_id 维度 sort) + 10，首次为 10
5. INSERT 新记录
6. 返回 { id, toolId, toolCode, sort }
```

### 5.2 取消收藏（removeFavorite）

```
1. WHERE user_id AND tool_code 查一条记录
2. 不存在 → 404
3. destroy()
```

### 5.3 列表查询（listFavorites）

- 使用 `findAndCountAll + distinct:true + col:'id'` 保证 count 与关键过滤正确
- 将 `tool.*` 过滤条件通过 `$tool.xxx$` 语法写到 outer WHERE，避免 `subQuery:false` 下 include.where 失效
- 排序：`sort ASC, favoritedAt DESC, id DESC`（手动排序优先；兜底按收藏时间倒序）
- 关键字模糊：`name LIKE` OR `description LIKE` OR `keyword LIKE`

### 5.4 拖拽排序（reorderFavorites）

```
1. 入参校验：
   - 非空数组
   - 无重复项（通过 Set 判定）
2. 取当前用户所有收藏 code 集合 currentSet
3. 若 currentSet.size !== orderedToolCodes.length → 400
4. orderedToolCodes 中任意 code 不在 currentSet → 400
5. 开启事务：按下标 i 依次 UPDATE sort=(i+1)*10
6. 提交或回滚
```

使用 `this.ctx.model.transaction(async (t) => {...})`（与 `member.ts` 风格一致）。

| 码 | HTTP | 语义 |
|----|------|------|
| 100901 | 404 | `FAVORITE_TOOL_NOT_AVAILABLE` 工具不存在或已下架 |

## 八、前端集成建议

### 8.1 工具列表页

进入页面时调用 `GET /api/favorites/codes` 拉取 code 集合，遍历工具列表时仅需 `codes.includes(tool.code)` 判断是否显示心形高亮，无需逐个调用 API。

```ts
const { data: favCodes } = await http.get<string[]>('/api/favorites/codes');
const favSet = new Set(favCodes);
// tool.isFavorited = favSet.has(tool.code)
```

### 8.2 收藏切换

```ts
async function toggle(toolCode: string, currentlyFavorited: boolean) {
  if (currentlyFavorited) {
    await http.delete(`/api/favorites/${toolCode}`);
  } else {
    await http.post('/api/favorites', { toolCode });
  }
}
```

### 8.3 个人收藏中心 - 拖拽

结合 `@dnd-kit/core` 或 `vue-draggable`，在 `onDragEnd` 取新顺序数组后 PUT 排序接口：

```ts
async function onReorder(newList: Fav[]) {
  // 乐观更新：先本地更新顺序
  setFavorites(newList);
  try {
    await http.put('/api/favorites/reorder', {
      orderedToolCodes: newList.map(f => f.toolCode),
    });
  } catch (e) {
    // 失败回滚
    await refetch();
  }
}
```
