# 全平台认证系统 API 设计文档

> 版本: 2.0 | 日期: 2026-04-10 | 状态: approved  
> 基于 P0 核心 API 扩展，新增微信登录、手机号登录、账号绑定、设备管理等模块

## 变更概览

在 P0 核心 API（13 张表 + 7 个认证路由）基础上新增：
- **2 张新表**: `user_profiles`（用户扩展信息）、`user_devices`（设备管理）
- **15 条新路由**: 微信登录 × 2、手机号登录 × 1、账号绑定 × 5、用户资料 × 2、设备管理 × 4、验证码升级 × 1
- **2 个新 Service**: `wechat.ts`（微信策略服务）、`sms.ts`（短信验证码安全服务）
- **新增错误码**: 验证码 1003xx、微信 1004xx、账号绑定 1005xx、安全 1006xx

## 新增接口详细设计

### POST /api/auth/wechat-login

微信统一登录入口，根据 `platform` 参数自动路由到对应登录策略。

**Request Body:**
```json
{
  "code": "微信授权码",
  "platform": "miniprogram",     // miniprogram | h5 | app | ios | android
  "clientId": "wechat-mp-xxx",
  "clientSecret": "xxx",
  "userInfo": {}                 // 可选，小程序端传用户信息
}
```

**Response:**
```json
{
  "code": 200,
  "message": "微信登录成功",
  "data": {
    "accessToken": "jwt...",
    "refreshToken": "jwt...",
    "expiresIn": 7200,
    "sessionId": "xxx",
    "isNewUser": true            // 是否新注册用户
  }
}
```

**策略分发:**
| platform | 微信接口 | 流程 |
|----------|----------|------|
| miniprogram | jscode2session | code → openid + session_key |
| h5 | OAuth2 (公众号) | code → access_token → userinfo |
| app/ios/android | OAuth2 (开放平台) | code → access_token → userinfo |

### POST /api/auth/phone-login

手机号验证码登录，首次登录自动注册新用户。

**Request Body:**
```json
{
  "phone": "13800138000",
  "code": "123456",
  "clientId": "h5-client",
  "clientSecret": "xxx",
  "platform": "h5"
}
```

### GET /api/auth/wechat-auth-url

获取微信 H5 端授权跳转 URL（前端重定向用）。

**Query Params:**
- `redirectUri` (必填) — 授权后回调地址
- `state` (可选) — 防 CSRF 状态码

**Response:**
```json
{
  "code": 200,
  "data": {
    "url": "https://open.weixin.qq.com/connect/oauth2/authorize?appid=xxx&redirect_uri=xxx&response_type=code&scope=snsapi_userinfo&state=xxx#wechat_redirect"
  }
}
```

### POST /api/auth/bind/phone

**Request Body:**
```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

### POST /api/auth/bind/wechat

**Request Body:**
```json
{
  "platform": "miniprogram",   // miniprogram | h5 | app
  "code": "微信授权码"
}
```

### POST /api/auth/unbind

**Request Body:**
```json
{
  "type": "wechat",            // phone | wechat | email
  "platform": "miniprogram"    // 微信解绑需指定平台
}
```

**安全规则:** 至少保留一种登录方式，否则返回 100503 错误码。

```json
  "pushToken": "fcm-token-xxx"
}
```

## 安全机制

### 密码登录渐进式锁定

| 失败次数 | 安全策略 |
|----------|----------|
| ≥ 5 次 | 需要输入图形验证码 |
| ≥ 8 次 | 账号临时锁定 15 分钟 |
| ≥ 10 次 | 账号临时锁定 60 分钟 |
| ≥ 15 次 | 账号永久锁定（需联系管理员） |

### 验证码安全策略

| 维度 | 限制 |
|------|------|
| 发送间隔 | 同一号码 60 秒内不可重复发送 |
| 日限额 | 单号码每日 10 条 |
| IP 限制 | 单 IP 每小时 20 条 |
| 验证失败 | 5 次失败锁定 30 分钟 |
| 原子消费 | Redis 分布式锁保证验证码不被重复使用 |
| 降级策略 | Redis 不可用时自动降级到数据库校验 |

## 数据库变更

### 新增表

**user_profiles** — 用户扩展信息表（1:1 关联 users）

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT UNSIGNED | 关联用户ID（唯一） |
| bio | VARCHAR(200) | 个人简介 |
| signature | VARCHAR(100) | 个人签名 |
| region_code | VARCHAR(20) | 所在地区行政编码 |
| language | VARCHAR(10) | 语言偏好（默认 zh-CN） |
| timezone | VARCHAR(50) | 时区（默认 Asia/Shanghai） |
| referral_code | VARCHAR(20) | 邀请码（唯一） |
| invited_by | BIGINT UNSIGNED | 邀请人用户ID |
| privacy_settings | JSON | 隐私设置 |
| notification_settings | JSON | 通知偏好设置 |

**user_devices** — 用户设备表（1:N 关联 users）

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT UNSIGNED | 用户ID |
| device_id | VARCHAR(100) | 设备唯一标识 |
| device_name | VARCHAR(100) | 设备名称 |
| device_type | VARCHAR(20) | 设备类型 |
| os_version | VARCHAR(50) | 系统版本 |
| app_version | VARCHAR(20) | 应用版本 |
| push_token | VARCHAR(500) | 推送Token |
| push_enabled | TINYINT(1) | 是否开启推送 |
| last_active_at | DATETIME | 最后活跃时间 |
| status | TINYINT UNSIGNED | 状态：0禁用，1正常 |

## 错误码扩展

| 范围 | 模块 | 错误码示例 |
|------|------|------------|
| 1003xx | 验证码 | 100301-无效, 100302-已使用, 100303-发送过快, 100304-日限额, 100305-IP限制 |
| 1004xx | 微信登录 | 100401-授权码无效, 100402-会话获取失败, 100403-OAuth失败, 100405-平台不支持 |
| 1005xx | 账号绑定 | 100501-已被其他用户绑定, 100502-已绑定, 100503-最后登录方式, 100504-绑定不存在 |
| 1006xx | 安全 | 100601-需要验证码, 100602-临时锁定, 100603-永久锁定, 100604-异地登录 |

## SSO 认证流程（升级版）

```
前端                          后端                          微信/短信
 │                             │                             │
 ├─── 密码登录 ────────────────▶│ checkSecurity → verifyPwd  │
 │    + captcha(如需)           │ → createSession → JWT       │
 │                             │                             │
 ├─── 微信登录 ────────────────▶│ validateClient              │
 │    code + platform          │──── jscode2session/OAuth ──▶│
 │                             │◀── openId/unionId ─────────│
 │                             │ findOrCreate user + oauth   │
 │                             │ → createSession → JWT       │
 │                             │                             │
 ├─── 手机号登录 ──────────────▶│ validateClient              │
 │    phone + code             │ verifyCode(Redis+DB)        │
 │                             │ findOrCreate user           │
 │                             │ → createSession → JWT       │
 │                             │                             │
 ├─── 发送验证码 ──────────────▶│ checkFrequency             │
 │                             │ generateCode → Redis+DB     │
 │                             │──── doSend ────────────────▶│
 │                             │                             │
```
