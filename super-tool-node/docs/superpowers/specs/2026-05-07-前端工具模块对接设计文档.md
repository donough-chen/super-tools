## 第三节 后端 API 契约（前端对接的参考）

> 本节仅列出本轮需用到的接口；完整契约见 `docs/api/tool/README.md` 和 `docs/api/admin-tool/README.md`。

所有接口统一响应格式：`{ code: number; data: T; message?: string; timestamp: number }`，其中成功为 `code: 200`，创建成功为 `code: 201`。

### 3.1 H5 端接口（4 个）

**`GET /api/tools/home`** — 首页聚合/分页双模式

Query：`categoryCode?` `keyword?` `page?=1` `pageSize?=20`。
- 无 `categoryCode` 且无 `keyword`：**聚合模式**，返回 `{ mode: 'aggregate', categories: [{ ..., tools: [...] }] }`
- 否则：**分页模式**，返回 `{ mode: 'paginated', categories: [...], tools: { list, total, page, pageSize, totalPages } }`

**`GET /api/tools/feature`** — 特色功能 Tab

Query：`page?=1` `pageSize?=20`。返回 `{ list, total, page, pageSize, totalPages }`（统一分页结构）。

**`GET /api/tools/member`** — 会员专属 Tab

结构同上。筛选条件为 `requiredLevelCode != 'free' OR requirePaid=1`。

**`GET /api/tools/:code/access`** — 使用前权限校验（需登录）

返回：
```ts
{
  allowed: boolean,
  reason?: 'need_level' | 'need_paid' | 'paid_expired',
  required?: { levelCode, levelName, requirePaid },
  current?: { levelCode, isPaid },
  tool?: { code, name, path },
}
```

### 3.2 Admin 端接口（10 个）

- 分类 CRUD × 4：`GET/POST/PUT/DELETE /api/admin/tool-categories[/:id]`
- 工具 CRUD × 5：`GET(list)/GET(:id)/POST/PUT/DELETE /api/admin/tools[/:id]`
- 批量发布：`PUT /api/admin/tools/batch-publish` body `{ ids: number[], status: 0|1 }`

> **路由顺序**：后端已把 `batch-publish` 放在 `/:id` 之前，前端直接调用即可。

### 4.3 菜单动态化（BasicLayout）

**核心函数**：`buildMenuFromRoutes(routes: IRouteWithName[]): MenuProps['items']`

```tsx
// BasicLayout.tsx 核心代码片段
import * as Icons from '@ant-design/icons';
import { useLocation, history } from 'umi';

interface RouteMeta { path?: string; name?: string; icon?: string; routes?: RouteMeta[]; }

function buildMenuFromRoutes(routes: RouteMeta[]): any[] {
  return routes
    .filter(r => !!r.name && !!r.path)   // 只保留显式声明 name 的节点
    .map(r => {
      const IconComp = r.icon && (Icons as any)[r.icon];
      const icon = IconComp ? <IconComp /> : undefined;
      const children = r.routes?.filter(c => !!c.name).length
        ? buildMenuFromRoutes(r.routes!)
        : undefined;
      return {
        key: r.path,
        icon,
        label: r.name,
        children,
        onClick: children ? undefined : () => history.push(r.path!),
      };
    });
}
```

**菜单路由来源**：

UmiJS 3 不直接导出运行时路由树给组件。解决方式：**把 `config/routes/index.ts` 同时导出一份静态常量**，作为 BasicLayout 的菜单数据源（两处"唯一真源"对齐：路由注册 + 菜单渲染）。若未来路由变化，改配置文件即可（菜单自动同步）。

替代方案：从 umi 的 `useRouteData()` 取运行时路由，但版本兼容性较差。**采用更稳的"直接 import 路由配置常量"方案**。

**跟随路由高亮**：
```tsx
const { pathname } = useLocation();
const selectedKeys = [pathname];
const openKeys = useMemo(() => {
  // 展开所有匹配前缀的父级
  return routes.flatMap(r => (pathname.startsWith(r.path) && r.routes ? [r.path] : []));
}, [pathname]);
```

### 5.3 Service `service/tool.ts`

```ts
import { request } from '@/utils';

const API = '/api/tools';

export const getHome = async (params?: {
  categoryCode?: string; keyword?: string; page?: number; pageSize?: number;
}) => {
  const qs = new URLSearchParams();
  if (params?.categoryCode) qs.set('categoryCode', params.categoryCode);
  if (params?.keyword)      qs.set('keyword', params.keyword);
  if (params?.page)         qs.set('page', String(params.page));
  if (params?.pageSize)     qs.set('pageSize', String(params.pageSize));
  const suffix = qs.toString() ? `?${qs.toString()}` : '';
  return await request.get(`${API}/home${suffix}`) || {};
};

export const getFeatureTools = async (params?: { page?: number; pageSize?: number }) => {
  const qs = new URLSearchParams();
  if (params?.page)     qs.set('page', String(params.page));
  if (params?.pageSize) qs.set('pageSize', String(params.pageSize));
  const suffix = qs.toString() ? `?${qs.toString()}` : '';

};

export const getMemberTools = async (params?: { page?: number; pageSize?: number }) => {

  const suffix = qs.toString() ? `?${qs.toString()}` : '';
```

```ts
export const useHomeStore = create<HomeState & HomeActions>()(
  immer((set, get) => ({
    categories: [],
    toolsByCategory: {},
    bannerTools: [],
    activeCategoryCode: '',
    loading: false,
    error: null,

    fetchHomeData: async () => {
      set(s => { s.loading = true; s.error = null; });

          getHome(),
          getFeatureTools({ page: 1, pageSize: 5 }),

          const bucket: Record<string, Tool[]> = {};
          aggCats.forEach(c => { bucket[c.code] = c.tools || []; });
          set(s => {
            s.categories = aggCats.map(({ tools: _ignored, ...rest }) => rest);
            s.toolsByCategory = bucket;
            if (!s.activeCategoryCode && aggCats.length > 0) {
              s.activeCategoryCode = aggCats[0].code;
            }
          });
        }

        if (featureRes?.code === 200 && featureRes.data?.list) {
          set(s => { s.bannerTools = featureRes.data.list as Tool[]; });
        }

        set(s => { s.loading = false; });
      } catch (err: any) {
        set(s => { s.loading = false; s.error = err?.message || '加载失败'; });
      }
    },

    setActiveCategoryCode: code => set(s => { s.activeCategoryCode = code; }),

    reset: () => set(() => ({

      activeCategoryCode: '', loading: false, error: null,
```

### 5.6 useToolClick Hook `hooks/useToolClick.ts`

```ts
import { useCallback, useState } from 'react';
import { useHistory } from 'umi';
import { useUserStore } from '../store/user';
import { checkToolAccess } from '../service/tool';
import type { Tool, AccessResult } from '../types/tool';

interface DialogState {
  visible: boolean;
  title: string;
  message: string;
  okText?: string;
  onOk?: () => void;
}

/**
 * 工具点击统一处理 hook。
 *
 * 返回 { onClick, dialog, closeDialog }
 * - onClick(tool) 由列表项 onClick 触发
 * - dialog 是弹窗状态，由页面传给 AppModal 展示
 * - 纯免费工具直接跳转；需校验工具先查登录/权限
 */
export function useToolClick() {
  const history = useHistory();
  const isLoggedIn = useUserStore(s => s.isLoggedIn);
  const [dialog, setDialog] = useState<DialogState>({ visible: false, title: '', message: '' });

  const closeDialog = useCallback(() => setDialog(d => ({ ...d, visible: false })), []);

  const onClick = useCallback(async (tool: Tool) => {
    // 1. 下架工具：禁止访问
    if (tool.status === 0) {
      setDialog({ visible: true, title: '提示', message: '该工具已下架' });
      return;
    }

    const needAuth = tool.requiredLevelCode !== 'free' || tool.requirePaid === 1;

    // 2. 纯免费（or 仅 isFeature=1 但无权限门槛）：直接跳转
    if (!needAuth) {
      history.push(tool.path);
      return;
    }

    // 3. 需校验 & 未登录：引导登录
    if (!isLoggedIn) {
      setDialog({
        visible: true,
        title: '需要登录',
        message: '使用该工具需要先登录账号',
        okText: '去登录',
        onOk: () => {
          closeDialog();
          history.push('/login?redirect=' + encodeURIComponent(tool.path));
        },
      });
      return;
    }

    // 4. 需校验 & 已登录：调 checkAccess
    try {
      const res: any = await checkToolAccess(tool.code);
      if (res?.code === 200 && res.data?.allowed) {
        history.push(tool.path);
        return;
      }
      const r = (res?.data || {}) as AccessResult;
      setDialog({
        visible: true,
        title: '升级会员',
        message: reasonToText(r),
        okText: '去开通',
        onOk: () => {
          closeDialog();
          history.push('/member');
        },
      });
    } catch {
      setDialog({ visible: true, title: '错误', message: '校验失败，请稍后重试' });
    }
  }, [history, isLoggedIn, closeDialog]);

  return { onClick, dialog, closeDialog };
}

function reasonToText(r: AccessResult): string {
  if (r.reason === 'need_level')   return `该功能需要「${r.required?.levelName || '更高等级'}」及以上等级`;
  if (r.reason === 'need_paid')    return '该功能需要付费会员';
  if (r.reason === 'paid_expired') return '您的付费会员已过期，请续费';
  return '您暂无权限使用该功能';
}
```

## 第六节 兼容性与风险

### 6.1 破坏性改动

| 改动 | 影响 | 应对 |
|------|------|------|
| 删除旧 `getBannerList / getToolCategories / searchTools / getFeaturedTools` | 若其他页面引用会编译报错 | 本次 **已审查** home/featured/search 引用，其他页面无使用；编译器会兜底 |
| `ToolItem` 旧类型删除 → `Tool` 新类型 | 引用旧字段（`url/subtitle/fontClass/iconTheme/contentType`）的地方编译错 | 改造已覆盖 home/featured/search 三页；其他地方在改造时统一检查 |
| `useHomeStore` state 结构变化 | 引用旧 `banners/fetchBanners` 的页面编译错 | home 页是唯一消费者，本轮改造 |
| `res.code === 0` → `res.code === 200` | 旧约定 0，新约定 200 | 在 featured/search 两处已明确修改 |

### 6.2 未覆盖场景

- **后端接口超时/5xx** — 当前 catch 后仅 console.error 或设置 error state。可后续增加全局 Toast 重试机制（超出本轮范围）。
- **并发登录态变化** — 用户在 home 页时刷新 token 失败，点击工具会拿到 401。useToolClick 会捕获到异常走错误弹窗，体验可接受。
- **Banner 图** — 后端 `tool.icon` 若空，banner 区将显示"首字母占位"而非精美大图。后续若需要独立运营 banner 再做。

### 6.3 回滚策略

所有改动都在前端代码，无数据库迁移；回滚方法：git revert 对应 commit 即可。后端接口和数据库保持不变。
