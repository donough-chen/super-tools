## 一、背景与目标

### 1.1 背景

后端已完成 RBAC 体系（迁移脚本 `006_add_rbac_init.sql` + `007_add_member_module.sql`），permissions 表已初始化 8 大模块共 72 条权限码。但管理端 `super-tools-admin` 当前只有 2 个工具页（`/tools/list`、`/tools/categories`），且：

1. 菜单完全由前端 `config/routes/` 硬编码生成，**未对接 RBAC**
2. 没有 `AuthButton`、`AuthWrapper` 等权限组件
3. 路径与 DB `permissions.path` 字段不一致（`/tools/list` vs DB `/tool`）
4. 用户身份接口未携带 `permissions` 字段

这导致即使后端权限矩阵完备，前端依然是"全员可见全部菜单"，权限体系名存实亡。

### 1.2 总体规划（3 个串行/并行 Spec）

### 1.3 Spec-B 目标

1. **菜单后端驱动**：登录后从后端拉取经权限过滤后的菜单树，前端不再硬编码菜单
2. **三级权限校验**：路由级（AuthWrapper）+ 按钮级（AuthButton）+ 接口级（403 处理）
3. **路径对齐 DB**：前端路由路径 = DB `permissions.path`，作为唯一真相
4. **缓存策略**：sessionStorage 缓存菜单与权限码，关闭浏览器或退出登录失效
5. **单测最小集**：覆盖核心权限工具与组件，~17 个用例

### 1.4 非目标（Out of Scope）

- ❌ 不实现 9 个业务管理页（归 Spec-C）
- ❌ 不补齐后端 4 个 controller（归 Spec-A）
- ❌ 不引入 qiankun/微前端（架构演进，不在本 Spec 范围）
- ❌ 不做后端菜单的版本号/灰度管理

## 二、关键决策快照

| # | 决策项 | 选择 | 理由摘要 |
|---|--------|------|----------|
| Q1 | 菜单/路由来源 | **B. 后端驱动菜单** | 路由组件仍写在前端 config，菜单树由 DB 驱动；改菜单只改 DB |

| Q5 | 缓存策略 | **B. sessionStorage** | 关浏览器/退出登录失效；同会话刷新无延迟；提供"刷新菜单"入口 |
| Q6 | 测试范围 | **A. 最小集** | 4 个核心单元、~17 个用例，ROI 最高 |
| Q7 | 单页模块菜单结构 | **D. 顶级目录 + 单一二级菜单** | 与 system 模块对称；DB 模型最干净；扩展友好 |

### 5.3 utils/permission.ts（纯函数）

```typescript
export function hasPermission(
  required: string | string[] | null | undefined,
  owned: string[],
): boolean {
  if (!required) return true;
  const set = new Set(owned);
  return Array.isArray(required)
    ? required.some(c => set.has(c))
    : set.has(required);
}

export function findMenuByPath(tree: MenuNode[], pathname: string): MenuNode | null {
  for (const n of tree) {
    if (n.path === pathname) return n;
    const c = findMenuByPath(n.children || [], pathname);
    if (c) return c;
  }
  return null;
}

export function findFirstLeaf(tree: MenuNode[]): MenuNode | null {
  for (const n of tree) {
    if (!n.children?.length) return n;
    const leaf = findFirstLeaf(n.children);
    if (leaf) return leaf;
  }
  return null;
}
```

### 5.4 utils/menuCache.ts

```typescript
const MENU_KEY = 'admin_menus';
const PERM_KEY = 'admin_permissions';

export const getCachedMenus = (): MenuNode[] | null => {
  try { return JSON.parse(sessionStorage.getItem(MENU_KEY) || 'null'); } catch { return null; }
};
export const setCachedMenus = (m: MenuNode[]) =>
  sessionStorage.setItem(MENU_KEY, JSON.stringify(m));

export const getCachedPermissions = (): string[] | null => {
  try { return JSON.parse(sessionStorage.getItem(PERM_KEY) || 'null'); } catch { return null; }
};
export const setCachedPermissions = (p: string[]) =>
  sessionStorage.setItem(PERM_KEY, JSON.stringify(p));

export const clearRbacCache = () => {
  sessionStorage.removeItem(MENU_KEY);
  sessionStorage.removeItem(PERM_KEY);
};
```

### 5.5 models/global.ts 扩展

```typescript
export interface GlobalModelState {
  collapsed: boolean;       // 已有
  menus: MenuNode[];        // 新增
  permissions: string[];    // 新增
  rbacReady: boolean;       // 新增
}

// effects 新增
*initRBAC(_, { call, put }) {
  const cMenus = getCachedMenus();
  const cPerms = getCachedPermissions();
  if (cMenus && cPerms) {
    yield put({ type: 'setRBAC', payload: { menus: cMenus, permissions: cPerms } });
    return;
  }
  try {
    const [menuRes, permRes] = yield all([call(fetchMenusApi), call(fetchPermissionsApi)]);
    const menus = menuRes?.data || [];
    const permissions = permRes?.data || [];
    setCachedMenus(menus);
    setCachedPermissions(permissions);
    yield put({ type: 'setRBAC', payload: { menus, permissions } });
  } catch {
    yield put({ type: 'setRBAC', payload: { menus: [], permissions: [] } });
  }
},

*refreshRBAC(_, { put }) {
  clearRbacCache();
  yield put({ type: 'setRBACReady', payload: false });
  yield put({ type: 'initRBAC' });
},

// reducers 新增
setRBAC(state, { payload }) {
  state.menus = payload.menus;
  state.permissions = payload.permissions;
  state.rbacReady = true;
},
setRBACReady(state, { payload }) { state.rbacReady = payload; },
resetRBAC(state) { state.menus = []; state.permissions = []; state.rbacReady = false; },
```

```tsx
  }, [rbacReady]);

  if (!isAuthenticated()) return null;
  if (!rbacReady) return <PageLoading />;
  return <>{children}</>;
};
```

```tsx
const HOME_MENU: MenuNode = {

function buildMenuFromAPI(nodes: MenuNode[]): MenuProps['items'] {
  return nodes.map(n => {
    const IconComp = n.icon ? (Icons as any)[n.icon] : null;
    const icon = IconComp ? <IconComp /> : undefined;
    if (n.children?.length) {

    return { key: n.path, icon, label: n.name, onClick: () => history.push(n.path) };

}
```

### 5.10 AuthWrapper

```tsx
import { useLocation, Redirect, useSelector } from 'umi';
import { findMenuByPath, hasPermission } from '@/utils/permission';
import PageLoading from '@/components/PageLoading';

const AuthWrapper: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const { menus, permissions, rbacReady } = useSelector((s: any) => s.global);
  const { pathname } = useLocation();

  if (!rbacReady) return <PageLoading />;

  const node = findMenuByPath(menus, pathname);
  if (!node || !hasPermission(node.code, permissions)) {
    const required = node?.code || `unmapped:${pathname}`;
    return <Redirect to={`/403?required=${encodeURIComponent(required)}`} />;
  }

  return <>{children}</>;
};

export default AuthWrapper;
```
