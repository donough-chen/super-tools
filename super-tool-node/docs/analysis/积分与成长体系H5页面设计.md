# 前端完整页面规范

## 前置：设计原则

```
核心原则：
├── 感知优先：让用户随时知道"我有多少积分、能做什么"
├── 行动引导：每个页面都有明确的下一步操作
├── 进度可见：等级、任务、积分消耗都有进度反馈
└── 层级清晰：主路径 ≤ 3 步可达

页面体系：
├── 会员中心（入口总览）
├── 等级详情页
├── 积分明细页
├── 任务中心页
└── 积分商城页
```

### 2.2 顶部卡片交互规范

```
等级进度条：
├── 颜色：按等级变化
│   青铜 #CD7F32 / 白银 #C0C0C0 / 黄金 #FFD700
│   铂金 #E5E4E2 / 钻石 #B9F2FF
├── 动画：页面加载时从 0 进度动画到当前进度（600ms ease-out）
├── 点击进度条：跳转等级详情页
└── 钻石用户：进度条替换为"已达最高等级"+ 星光动效

数据卡片（积分/累计/连签）：
├── 点击"可用积分"→ 跳转积分明细页
├── 点击"累计积分"→ 跳转积分明细页（历史 Tab）
└── 点击"连签天数"→ 跳转任务中心（日常任务 Tab）

过期提醒条：
├── 有过期积分时展示，无则隐藏
├── 点击"立即使用"→ 跳转积分商城
├── 右侧"×"可关闭（当日不再展示，次日重置）
└── 距过期 ≤ 7 天：背景色变为警告橙色
```

### 3.2 等级对比交互

```
等级节点点击交互：
├── 点击已达到的等级节点 → 展示该等级权益详情（回顾）
├── 点击未达到的等级节点 → 展示该等级权益预览 + 升级所需成长值
└── 当前等级节点 → 高亮 + 脉冲动效

权益卡片状态：
├── 已解锁：正常展示，左侧绿色✅图标
├── 锁定中：灰色蒙层，右上角🔒图标
│           底部展示"差 X 成长值解锁"
└── 对比展示：当前等级 vs 下一等级并排，突出差异

升级激励文案规则：
├── 差值 ≤ 200：  "再消费 {X} 元即可升级！冲刺一下～"
├── 差值 ≤ 1000： "距升级还差 {X} 成长值，继续加油！"
├── 差值 ≤ 5000： "距升级还差 {X} 成长值，预计消费 {X} 元"
└── 钻石用户：    "您已是最高等级，感谢您的长期支持 🎉"
```

### 4.2 明细条目规范

```
条目颜色规范：
├── 🟢 绿色：积分获得（points > 0）
├── 🔴 红色：积分消耗（points < 0，非过期）
├── ⚫ 灰色：积分过期（type = 'expired'）
└── 🔵 蓝色：系统调整（type = 'admin_adjust'）

条目信息层级：
第一行：类型描述 + 积分变动（右对齐，加粗）
第二行：补充说明（订单号/任务名/来源）+ 时间（右对齐，灰色）
第三行（可选）：积分构成拆分（基础 + 等级加成）

消费返积分的拆分展示：
├── 总积分 ≤ 100：不拆分，直接显示总数
└── 总积分 > 100：展示"基础 +X / 等级加成 +Y"

时间展示规则：
├── 今天：显示"今天 HH:mm"
├── 昨天：显示"昨天"
├── 本周：显示"周X"
├── 今年：显示"M月D日"
└── 跨年：显示"YYYY年M月D日"
```
