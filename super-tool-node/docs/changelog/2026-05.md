# 2026-05 变更日志

## 2026-05-06 — 工具管理模块上线

### 新增功能

**数据层：**
- 新增 `tool_categories` 表（11 个预置分类）
- 新增 `tools` 表（233 个预置工具，来源 `test1.js`）
- Migration：`database/004_add_tools_system.sql`（v2.3.0）
- 种子生成脚本：`scripts/build-tools-seed.js`

**Model：**
- `app/model/tool_category.ts` — `ToolCategory` 模型
- `app/model/tool.ts` — `Tool` 模型 + 与 `ToolCategory` 的关联

**Service：**
- `app/service/tool.ts` — `ToolService`
  - H5 端：`getHomeData`（聚合/分页双模式）、`getFeatureTools`、`getMemberTools`、`checkToolAccess`
  - 管理端：分类 CRUD、工具 CRUD、`batchPublish` 批量发布/下架
  - Redis 缓存治理：`tool:categories:all` (600s)、`tool:home:aggregate` (300s)

**Controller：**
- `app/controller/tool.ts` — H5 端 4 个 action
- `app/controller/admin/tool.ts` — 管理端 10 个 action

**Router：** 新增 14 条路由（H5 端 4 条 + 管理端 10 条）

**错误码：** 新增 `1008xx` 区间（9 条工具模块错误码）

**接口清单：**

H5 端（4 个）：
- `GET /api/tools/home` — 首页聚合/分页
- `GET /api/tools/feature` — 特色功能 Tab
- `GET /api/tools/member` — 会员专属 Tab
- `GET /api/tools/:code/access` — 使用前权限校验（需登录）

管理端（10 个）：
- `GET/POST /api/admin/tool-categories`
- `PUT/DELETE /api/admin/tool-categories/:id`
- `GET/POST /api/admin/tools`
- `GET/PUT/DELETE /api/admin/tools/:id`
- `PUT /api/admin/tools/batch-publish`

### 设计决策

1. **权限模型**：使用 `required_level_code` + `require_paid` 两个正交字段，而非权限码体系
2. **主键风格**：自增 `id` + unique `code`（与 `member_levels` 等既有表一致）
3. **H5 首页接口**：双模式单接口（无参聚合、有参分页），查询 `/home` 不挂鉴权；使用工具时才通过 `/access` 懒校验
4. **Tab 筛选**：严格口径，允许一个工具同时出现在特色 Tab 和会员专属 Tab

### 风险与注意事项

- 本次迁移仅新增表，不影响既有 `users`/`user_members`/`roles` 等模块
- `INSERT IGNORE INTO` 幂等，Migration 重复执行安全
- 外键 `tools.category_id → tool_categories.id ON DELETE RESTRICT`，禁止删除尚有工具的分类（Service 层提供友好错误提示）
- `category_code` 为 tools 表的冗余字段，`updateCategory` 修改 code 时 Service 会同步 tools.category_code
