## 2026-04-10 全平台认证系统

### 新增功能
- ✅ **微信登录（策略模式）** — 统一入口 `/api/auth/wechat-login`，按 `platform` 参数自动分发到小程序 jscode2session / H5 OAuth2 / APP SDK 三种策略
- ✅ **手机号验证码登录** — `/api/auth/phone-login`，首次登录自动创建账户（登录即注册）
- ✅ **获取微信H5授权URL** — `/api/auth/wechat-auth-url`，用于 H5 端发起微信 OAuth2 授权跳转
- ✅ **账号绑定系统** — 绑定手机号 / 绑定微信 / 绑定邮箱 / 解绑 / 查询绑定状态（5个接口）
- ✅ **用户扩展信息** — 获取完整资料 `/api/users/profile/extra` + 更新资料 `PUT /api/users/profile`
- ✅ **设备管理** — 注册设备 / 设备列表 / 移除设备 / 推送开关（4个接口）
- ✅ **渐进式登录安全** — 5次→验证码, 8次→锁定15min, 10次→锁定60min, 15次→永久锁定
- ✅ **验证码限流保护** — 60s间隔 / 每日10条 / IP每小时20条 / 5次验证失败锁30分钟

### 新增表
- ✅ `user_profiles` — 用户扩展信息表（1:1 关联 users），含个人简介/签名/地区/语言/时区/邀请码/隐私设置/通知设置
- ✅ `user_devices` — 用户设备管理表（1:N 关联 users），含设备标识/类型/推送Token/活跃时间

### 新增文件
- `database/002_add_user_profiles_and_devices.sql` — 数据库迁移脚本
- `app/model/user_profile.ts` — UserProfile Model
- `app/model/user_device.ts` — UserDevice Model
- `app/service/wechat.ts` — 微信登录策略服务（小程序/H5/APP三端）
- `app/service/sms.ts` — 短信验证码服务（含 Redis 原子消费 + 限流）

### 扩展文件
- `app/constants/errorCodes.ts` — 新增验证码(1003xx)/微信(1004xx)/绑定(1005xx)/安全(1006xx)/手机号(100205) 错误码
- `app/service/auth.ts` — 新增微信登录/手机号登录/绑定/解绑/安全检查等方法
- `app/service/user.ts` — 新增 profile 扩展信息和设备管理方法
- `app/controller/auth.ts` — 新增 8 个 controller 方法
- `app/controller/user.ts` — 新增 6 个 controller 方法
- `app/router.ts` — 从 30 条路由扩展到 45 条
- `app/middleware/auth.ts` — 白名单新增 3 个免认证路由
- `config/config.default.ts` — 新增 wechat/sms/verifyCode 配置

### 文档更新
