# docs — AI 协作开发技术总结文档库

本目录用于系统化记录每次与 AI Agent 对话的技术总结，积累项目开发知识资产，便于团队成员查阅和后续开发参考。

---

## 目录用途

- 记录每次 AI 协作开发的完整技术过程
- 沉淀解决方案、设计决策和踩坑经验
- 为后续功能迭代提供参考依据
- 方便新成员快速了解项目演进历史

---

## 文档命名规范

按 **日期 + 主题关键词** 命名，使用小写字母和连字符：

```
YYYY-MM-DD-[主题关键词].md
```

**示例：**
```
2024-03-20-globalmodal-component.md        # GlobalModal 组件封装
2024-03-21-announcement-module.md          # 更新公告模块开发
2024-03-22-header-login-refactor.md        # Header 登录模块重构
```

---

## 文档内容规范

每篇文档应包含以下章节：

| 章节 | 说明 |
|------|------|
| **对话日期** | 本次对话的日期和时间 |
| **需求背景** | 功能需求描述和业务背景 |
| **技术方案** | 整体设计思路和架构决策 |
| **实现详情** | 新增/修改的文件清单及关键代码说明 |
| **问题与修复** | 开发过程中遇到的问题及解决方法 |
| **文件变更记录** | 涉及的文件路径和变更类型（新增/修改/删除） |
| **后续计划** | 待完善的功能或已知限制 |
