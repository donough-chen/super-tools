## 一、页面分类

### 一级页面（Tab 页面）

含底部导航栏，KeepAlive 缓存，切换时保持滚动和状态：

| 页面 | 路径 | 组件 | 文件 |
|------|------|------|------|
| 首页 | `/` | `HomePage` | `pages/home/` |
| 收藏 | `/favorites` | `FavoritesPage` | `pages/favorites/` |
| 特色 | `/featured` | `FeaturedPage` | `pages/featured/` |
| 网站 | `/sites` | `SitesPage` | `pages/sites/` |
| 我的 | `/mine` | `MinePage` | `pages/mine/` |

### 二级页面

含返回按钮，无底部导航栏：

| 页面 | 路径 | 组件 | 文件 |
|------|------|------|------|
| 搜索 | `/search` | `SearchPage` | `pages/search/` |
| 登录 | `/login` | `LoginPage` | `pages/login/` |
| 收藏排序 | `/favorites/reorder` | `FavoritesReorderPage` | `pages/favorites/reorder/` |
| 设置 | `/settings` | `SettingsPage` | `pages/settings/` |
| 个人信息 | `/profile` | `ProfilePage` | `pages/profile/` |
| 会员 | `/member` | `MemberPage` | `pages/member/` |
| 使用帮助 | `/help` | `HelpPage` | `pages/help/` |
| 关于我们 | `/about` | `AboutPage` | `pages/about/` |

## 二、新增页面 SOP

### 步骤 1：创建页面文件

在 `pages/` 下创建目录，包含 `index.tsx` 和 `index.less`：

```
pages/
└── new-page/
    ├── index.tsx
    └── index.less
```

### 步骤 2：编写页面组件

**一级页面模板：**

```tsx
import React, { useEffect } from 'react';
import { useHistory } from 'umi';
import { useGlobalStore } from '../../store';
import AppHeader from '../../components/AppHeader';
import AppTabBar from '../../components/AppTabBar';
import { TAB_BAR_ITEMS } from '../../constants';
import './index.less';

const NewPage: React.FC = () => {
  const { tabBarMode, activeTabBarKey, setActiveTabBarKey } = useGlobalStore();
  const history = useHistory();

  return (
    <div className="page-new">
      <AppHeader
        title="新页面"
        buttons={[
          { type: 'agent' },
          { type: 'search', onClick: () => history.push('/search') },
        ]}
      />

      <main className="page-new__content">
        {/* 页面内容 */}
      </main>

      <AppTabBar
        mode={tabBarMode}
        activeKey={activeTabBarKey}
        items={TAB_BAR_ITEMS}
        onChange={key => {
          setActiveTabBarKey(key);
          history.push(key === 'home' ? '/' : `/${key}`);
        }}
      />
    </div>
  );
};

export default NewPage;
```

**二级页面模板：**

```tsx
import React from 'react';
import { history } from 'umi';
import AppHeader from '../../components/AppHeader';
import './index.less';

const NewSubPage: React.FC = () => {
  return (
    <div className="page-new-sub">
      <AppHeader
        title="新二级页面"
        showBack
        onBack={() => history.goBack()}
      />

      <main className="page-new-sub__content">
        {/* 页面内容 */}
      </main>
    </div>
  );
};

export default NewSubPage;
```

### 步骤 3：编写样式

```less
@import '~@/assets/variables.less';

.page-new {
  min-height: 100vh;
  background: var(--bg-page);

  &__content {
    padding-top: var(--header-height);
    padding-left: var(--spacing-md);
    padding-right: var(--spacing-md);
    min-height: calc(100vh - var(--header-height));
  }
}
```

### 步骤 4：注册路由

在以下三个配置文件中添加路由（保持一致）：

- `.umirc.dev.ts`
- `.umirc.preview.ts`
- `.umirc.prod.ts`

```typescript
routes: [
  {
    exact: false,
    path: '/',
    component: '@/layouts',
    routes: [
      // ... 已有路由
      { path: '/new-page', component: '@/pages/new-page', title: '新页面' },
    ],
  },
]
```

### 步骤 5：（一级页面）注册 TabBar

如果是新的一级页面，在 `constants/index.ts` 中添加导航项：

```typescript
export const TAB_BAR_ITEMS = [
  // ... 已有项
  { key: 'new-page', name: '新页面', icon: '', activeIcon: '' },
];
```

同时在 `components/KeepAlive/CacheRoute.tsx` 的 `CACHE_ROUTES` 中添加缓存路由。

### 步骤 6：（可选）创建 Store

如需独立状态管理，在 `store/` 中创建对应 Store：

```typescript
// store/newPage.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';

export const useNewPageStore = create(...);
```

并从 `store/index.ts` 导出：

```typescript
export { useNewPageStore } from './newPage';
```

## 三、页面布局规范

### 高度计算

```
主体内容区高度 = 100vh
  - var(--header-height)       // 头部导航 88px
  - var(--tabs-height)         // Tab 栏 80px（有 Tab 时）
  - var(--tabbar-height)       // 底部导航（仅 flat 模式）
```

### 一级页面结构

```
┌──────────────────────┐
│ AppHeader (fixed)    │ ← --header-height
├──────────────────────┤
│ AppTabs (optional)   │ ← --tabs-height（可选）
├──────────────────────┤
│                      │
│ 主体内容区 (scroll)   │ ← 自适应高度
│                      │
├──────────────────────┤
│ AppTabBar            │ ← float: 悬浮覆盖 / flat: 占据空间
└──────────────────────┘
```

### 二级页面结构

```
┌──────────────────────┐
│ AppHeader (showBack) │ ← --header-height
├──────────────────────┤
│                      │
│ 主体内容区 (scroll)   │ ← 100vh - header
│                      │
└──────────────────────┘
```

## 四、各页面功能详解

### 4.1 首页 Home

**核心功能：**
- 搜索框 + `IntersectionObserver` 检测可见性 → 控制 Header search 按钮显隐
- Banner 轮播：原生 `scroll-snap` + `useSwipe` 手势 + 指示器同步
- 工具分类列表：支持 5 种展示模式（grid/card/flow/single/double）
- 工具图标：优先 `iconfont`（fontClass），降级 `img`（icon URL）

**工具列表展示模式：**

| 模式 | 布局 | 展示内容 |
|------|------|---------|
| `grid` | 4 列网格 | 图标 + 名称 |
| `card` | 3 列网格 | 图标 + 名称 + 副标题 |
| `flow` | 自适应胶囊 | 名称 |
| `single` | 单列列表 | 图标 + 名称 + 副标题 + 箭头 |
| `double` | 2 列网格 | 图标 + 名称 + 副标题 |

### 4.2 收藏页 Favorites

- 收藏工具列表，支持 `single` / `double` 两种模式
- 空状态引导文案
- Header 按钮：`[agent, search, add]`

### 4.3 特色页 Featured

- 双 Tab 模式：特色功能 / 会员专属
- `useSwipe` 左右滑动切换 + 跟手偏移动画
- 边界阻尼效果（首尾 Tab 偏移 × 0.3）
- CSS 过渡动画（slide-left / slide-right）

### 4.4 网站页 Sites

- 多 Tab 模式，分类由接口动态返回
- 与特色页相同的滑动切换机制
- 排序功能：最多使用 / 最多收藏 / 最新投稿
- 网站项点击 `window.open` 打开外链

### 4.5 我的页 Mine

- 用户信息卡片（未登录 → 登录引导 / 已登录 → 头像 + 用户名）
- 功能菜单列表：关于我们 / 更多作品 / 设置 / 使用帮助 / 退出登录
- 退出登录使用 `AppModal` 确认弹窗

### 4.6 搜索页 Search

- 输入框自动聚焦（`autoFocus`）
- 回车触发搜索（`onKeyPress Enter`）
- 调用 `searchTools` 接口获取结果

### 4.7 登录页 Login

- 登录 / 注册双模式，Tab 切换（胶囊式 UI）
- 登录表单：用户名 + 密码，前端校验（非空）
- 注册表单：用户名 + 邮箱 + 昵称（可选）+ 密码 + 确认密码
- 注册表单校验：用户名至少 3 字符、邮箱格式、密码至少 8 位含大小写字母和数字、确认密码一致性
- Token 持久化：登录成功自动保存 Token 到 localStorage
- 注册成功后 1.5 秒自动切换到登录模式并保留用户名
- 全局错误 / 成功消息提示
- 登录成功 `history.goBack()` 返回上一页
- 回车键提交支持

### 4.8 设置页 Settings

- 底部导航模式：悬浮 / 平铺
- 工具列表模式：5 种可选
- 收藏列表模式：单列 / 双列
- 主题色：6 种预设颜色

## 五、页面间导航

### 路由跳转方式

```tsx
import { history, useHistory } from 'umi';

// 方式一：直接使用 history 对象
history.push('/search');
history.goBack();

// 方式二：通过 Hook
const history = useHistory();
history.push('/search');
```

### TabBar 导航

```tsx
// 在 AppTabBar onChange 中统一处理
onChange={key => {
  setActiveTabBarKey(key);
  history.push(key === 'home' ? '/' : `/${key}`);
}}
```

### 注意事项

- 一级页面间切换通过 `AppTabBar` 组件，不要直接使用 `history.push`
- 二级页面返回使用 `history.goBack()`，不要 `history.push` 回一级页面
- 路由跳转前确保 `activeTabBarKey` 与目标路由一致
