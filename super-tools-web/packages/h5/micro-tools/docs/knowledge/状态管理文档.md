## 一、架构概述

本项目采用 **Zustand + immer** 中间件进行状态管理，按业务模块拆分 Store，统一从 `store/index.ts` 导出。

### 为什么选择 Zustand

| 对比项 | Zustand | DVA (Redux) |
|--------|---------|-------------|
| 样板代码 | 极少，直接定义 State + Action | 大量（action type、reducer、effect、model） |
| 异步操作 | 原生 async/await | saga/effect 中间件 |
| 学习成本 | 低 | 高 |
| TypeScript | 原生支持 | 需额外类型定义 |
| 包体积 | ~1KB | ~10KB+ |

### Store 架构

```
store/
├── index.ts          → 统一导出
├── global.ts         → useGlobalStore（全局设置）
├── home.ts           → useHomeStore（首页数据）
├── favorites.ts      → useFavoritesStore（收藏数据）
├── sites.ts          → useSitesStore（网站数据）
└── user.ts           → useUserStore（用户数据）
```

## 二、全局设置 Store — `useGlobalStore`

### 状态字段

```typescript
interface GlobalState {
  tabBarMode: 'float' | 'flat';               // 底部导航栏模式
  toolListMode: 'grid' | 'card' | 'flow' | 'single' | 'double';  // 工具列表模式
  favListMode: 'single' | 'double';           // 收藏列表模式
  themeColor: string;                          // 主题色（HEX）
  sortType: 'most_used' | 'most_fav' | 'newest';  // 排序方式
  activeTabBarKey: string;                     // 当前底部导航激活项
  isSearchBoxVisible: boolean;                 // 首页搜索框可见状态
}
```

### Actions

| Action | 参数 | 说明 |
|--------|------|------|
| `setTabBarMode(mode)` | `'float' \| 'flat'` | 切换导航栏模式，自动持久化 |
| `setToolListMode(mode)` | `ToolListMode` | 切换工具列表展示模式，自动持久化 |
| `setFavListMode(mode)` | `'single' \| 'double'` | 切换收藏列表模式，自动持久化 |
| `setThemeColor(color)` | `string` (HEX) | 更新主题色 + 同步 CSS 变量 + 持久化 |
| `setSortType(type)` | `SortType` | 更新排序方式（运行时，不持久化） |
| `setActiveTabBarKey(key)` | `string` | 更新激活导航项（运行时） |
| `setSearchBoxVisible(visible)` | `boolean` | 更新搜索框可见状态（IntersectionObserver 驱动） |
| `restoreSettings()` | — | 从 localStorage 恢复所有持久化设置 |

### 持久化策略

| 字段 | 持久化 | 存储 Key |
|------|--------|---------|
| `tabBarMode` | ✅ | `micro-tools-settings` |
| `toolListMode` | ✅ | `micro-tools-settings` |
| `favListMode` | ✅ | `micro-tools-settings` |
| `themeColor` | ✅ | `micro-tools-settings` + CSS 变量 |
| `sortType` | ❌ | 运行时 |
| `activeTabBarKey` | ❌ | 运行时 |
| `isSearchBoxVisible` | ❌ | 运行时（IntersectionObserver 驱动） |

### 主题色同步机制

```
设置页修改主题色
  ├── setThemeColor(color)
  ├── 更新 Zustand Store state
  ├── document.documentElement.style.setProperty('--primary-color', color)
  └── localStorage.setItem('micro-tools-settings', JSON.stringify({...}))
```

### 使用示例

```tsx
import { useGlobalStore } from '../../store';

const { tabBarMode, setTabBarMode, themeColor, setThemeColor } = useGlobalStore();

// 切换导航模式
setTabBarMode('flat');

// 修改主题色（会自动同步 CSS 变量 + localStorage）
setThemeColor('#52c41a');
```

## 三、首页 Store — `useHomeStore`

### 状态字段

```typescript
interface HomeState {
  banners: BannerItem[];          // Banner 列表
  categories: ToolCategory[];     // 工具分类列表（含 expanded 状态）
  loading: boolean;               // 加载状态
  error: string | null;           // 错误信息
  query: Record<string, string>;  // URL 查询参数
}
```

### 核心类型

```typescript
interface BannerItem {
  id: string;
  imageUrl: string;
  linkUrl: string;
  title: string;
}

type IconTheme = 'default' | 'orange' | 'green' | 'blue' | 'purple'
  | 'red' | 'teal' | 'pink' | 'indigo' | 'amber' | 'cyan';

interface ToolItem {
  id: string;
  name: string;
  icon: string;
  fontClass?: string;            // iconfont class 名称
  iconTheme?: IconTheme;         // 图标颜色主题
  subtitle?: string;
  category: string;
  url: string;
  contentType: 'native' | 'iframe' | 'external';
}

interface ToolCategory {
  id: string;
  name: string;
  icon?: string;
  tools: ToolItem[];
  expanded: boolean;             // 展开/折叠状态
}
```

### Actions

| Action | 说明 |
|--------|------|
| `initQuery(query)` | 初始化 URL 查询参数 |
| `fetchBanners()` | 异步获取 Banner 列表 |
| `fetchCategories()` | 异步获取工具分类列表 |
| `toggleCategory(categoryId)` | 切换分类展开/折叠 |
| `reset()` | 重置为初始状态 |

### 使用示例

```tsx
const { banners, categories, loading, fetchBanners, fetchCategories, toggleCategory } = useHomeStore();

useEffect(() => {
  fetchBanners();
  fetchCategories();
}, []);
```

## 五、网站 Store — `useSitesStore`

### 状态字段

```typescript
interface SitesState {
  categories: SiteCategory[];   // 网站分类 Tab
  activeTabIndex: number;       // 当前激活分类索引
  sites: SiteItem[];            // 网站列表
  loading: boolean;
  error: string | null;
}
```

### 核心类型

```typescript
interface SiteCategory {
  id: string;
  name: string;
  icon?: string;
}

interface SiteItem {
  id: string;
  name: string;
  icon: string;
  url: string;
  userCount: number;   // 使用人数
  favCount: number;    // 收藏人数
  createdAt: string;   // 创建时间
}
```

### Actions

| Action | 参数 | 说明 |
|--------|------|------|
| `fetchCategories()` | — | 获取网站分类列表 |
| `setActiveTab(index)` | `number` | 切换当前分类 |
| `fetchSites(categoryId, sortType?)` | `string, SortType?` | 获取指定分类下的网站列表 |
| `reset()` | — | 重置为初始状态 |

### 使用示例

```tsx
const { categories, activeTabIndex, sites, fetchCategories, setActiveTab, fetchSites } = useSitesStore();
const { sortType } = useGlobalStore();

useEffect(() => {
  fetchCategories();
}, []);

useEffect(() => {
  if (categories.length > 0) {
    fetchSites(categories[activeTabIndex].id, sortType);
  }
}, [activeTabIndex, categories, sortType]);
```

## 六、用户 Store — `useUserStore`

### 状态字段

```typescript
interface UserState {
  isLoggedIn: boolean;          // 登录态
  userInfo: UserInfo | null;    // 用户信息
  loading: boolean;
  error: string | null;         // 错误信息
}

interface UserInfo {
  id: number;
  uuid: string;
  username: string;
  nickname: string;
  avatar: string;
  email: string;
  userType: number;             // 0 普通 / 1 VIP
  vipExpireAt?: string;
  phone?: string;
}
```

### Token 持久化

| 项目 | 说明 |
|------|------|
| 存储 Key | `super-tools-auth-token` |
| 存储介质 | `localStorage` |
| 存储内容 | `{ accessToken, refreshToken, expiresAt }` |
| 过期策略 | 提前 60 秒判定过期 |
| 续期机制 | `refreshToken` 自动续期 |

### Actions

| Action | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `initAuth()` | — | `void` | 从本地 Token 恢复登录态（应用启动时调用） |
| `login(username, password)` | `string, string` | `{ success: boolean; message: string }` | 账号密码登录，自动保存 Token |
| `register(params)` | `{ username, email, password, nickname? }` | `{ success: boolean; message: string }` | 用户注册（不自动登录） |
| `logout()` | — | `void` | 退出登录，清除 Token，重置状态 |
| `refreshToken()` | — | `boolean` | Token 续期，返回是否成功 |
| `getAccessToken()` | — | `string \| null` | 获取有效的 AccessToken（供请求拦截器使用） |
| `fetchUserProfile()` | — | `void` | 获取当前用户资料 |
| `reset()` | — | `void` | 重置为初始状态 |

### 使用示例

```tsx
const { isLoggedIn, userInfo, error, login, logout, register, initAuth } = useUserStore();

// 应用启动时恢复登录态
useEffect(() => {
  initAuth();
}, []);

// 登录
const result = await login('admin', 'Admin@123456');
if (result.success) {
  history.goBack();
} else {
  console.error(result.message);
}

// 注册
const regResult = await register({ username: 'test', email: 'test@example.com', password: 'Test@12345' });
if (regResult.success) {
  // 注册成功，切换到登录模式
}

// 退出
await logout();
history.push('/');
```

## 七、开发规范

### 新建 Store 规范

1. 在 `store/` 目录下新建文件，命名使用 camelCase
2. 使用 `create` + `immer` 中间件
3. 分离 State 接口和 Actions 接口
4. 提供 `reset()` 方法恢复初始状态
5. 从 `store/index.ts` 统一导出

### 模板

```typescript
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';

interface XxxState {
  // 状态字段
}

interface XxxActions {
  // 操作方法
  reset: () => void;
}

const initialState: XxxState = {
  // 初始值
};

export const useXxxStore = create<XxxState & XxxActions>()(
  immer(set => ({
    ...initialState,

    // 实现 actions...

    reset: () => {
      set(() => ({ ...initialState }));
    },
  })),
);
```

### 注意事项

- **immer 中间件**：在 `set` 回调中可直接修改 state 对象（`state.xxx = yyy`）
- **异步操作**：直接在 action 中使用 `async/await`，无需额外中间件
- **持久化**：需要持久化的状态在 action 中手动调用 `saveSettings`
- **类型复用**：跨 Store 的类型使用 `import type` 导入
