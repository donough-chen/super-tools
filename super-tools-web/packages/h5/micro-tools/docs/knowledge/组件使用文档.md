## 二、AppHeader 头部导航组件

### 功能描述

- 固定顶部，毛玻璃效果（`backdrop-filter: blur(10px)`）
- 支持一级页面（标题 + 按钮组）和二级页面（返回 + 标题）
- 高度：`88px`（CSS 变量 `--header-height`）

### Props

```typescript
interface AppHeaderProps {
  /** 页面标题 */
  title: string;
  /** 右侧按钮配置列表 */
  buttons?: HeaderButtonConfig[];
  /** 是否显示返回按钮（二级页面使用） */
  showBack?: boolean;
  /** 返回按钮回调 */
  onBack?: () => void;
}

interface HeaderButtonConfig {
  /** 按钮类型 */
  type: 'search' | 'agent' | 'settings' | 'sort' | 'add' | 'scan' | 'placeholder';
  /** 是否可见，支持静态布尔值或动态函数 */
  visible?: boolean | (() => boolean);
  /** 点击回调 */
  onClick?: () => void;
}
```

### 按钮类型说明

| 类型 | 图标 | 用途 |
|------|------|------|
| `search` | 搜索图标 | 搜索框不可见时显示，点击跳转搜索页 |
| `agent` | 占位图标 | 智能体入口（预留） |
| `settings` | 设置图标 | 弹出设置面板 |
| `sort` | 排序图标 | 弹出排序选项 |
| `add` | 加号图标 | 添加收藏 / 跳转首页 |
| `scan` | 扫码图标 | 调用 AppSdk 扫码 |
| `placeholder` | 无 | 占位用，维持布局 |

### 使用示例

**一级页面：**

```tsx
<AppHeader
  title="首页"
  buttons={[
    {
      type: 'search',
      visible: () => !isSearchBoxVisible,
      onClick: () => history.push('/search'),
    },
    { type: 'agent' },
    { type: 'settings' },
  ]}
/>
```

**二级页面：**

```tsx
<AppHeader
  title="设置"
  showBack
  onBack={() => history.goBack()}
/>
```

## 三、AppTabs Tab 切换组件

### 功能描述

- 紧贴头部导航下方，高度 `80px`（CSS 变量 `--tabs-height`）
- 支持双 Tab 模式和多 Tab 模式
- Active 指示块平移动画（非跳变）

### Props

```typescript
interface AppTabsProps {
  /** Tab 模式 */
  mode: 'double' | 'multiple';
  /** Tab 项列表 */
  tabs: TabItem[];
  /** 当前激活 Tab 索引 */
  activeIndex: number;
  /** Tab 切换回调 */
  onChange: (index: number) => void;
}

interface TabItem {
  key: string;
  name: string;
  /** 图标 URL（多 Tab 模式使用） */
  icon?: string;
}
```

### 两种模式对比

| 特性 | 双 Tab (`double`) | 多 Tab (`multiple`) |
|------|---|---|
| 适用场景 | 仅 2 个 Tab | Tab 数量 ≥ 3 |
| 样式 | 等宽平铺，共享毛玻璃 | 胶囊样式，横向滚动 |
| 指示器 | 整体平移 + 背景色过渡 | Active 背景色填充 |
| 图标 | 不支持 | 支持图标 + 名称 |
| 自动居中 | 不需要 | 点击后自动 scrollToCenter |

### 使用示例

**双 Tab 模式（特色页）：**

```tsx
<AppTabs
  mode="double"
  tabs={[
    { key: 'featured', name: '特色功能' },
    { key: 'vip', name: '会员专属' },
  ]}
  activeIndex={activeIndex}
  onChange={handleTabChange}
/>
```

**多 Tab 模式（网站页）：**

```tsx
<AppTabs
  mode="multiple"
  tabs={categories.map(cat => ({
    key: cat.id,
    name: cat.name,
    icon: cat.icon,
  }))}
  activeIndex={activeTabIndex}
  onChange={handleTabChange}
/>
```

## 四、AppTabBar 底部导航栏组件

### 功能描述

- 一级页面底部导航
- 支持悬浮和平铺两种模式（可在设置页切换）
- Active 状态图标弹性放大，颜色跟随主题色

### Props

```typescript
interface AppTabBarProps {
  /** 导航栏模式 */
  mode: 'float' | 'flat';
  /** 当前激活导航项 key */
  activeKey: string;
  /** 导航项列表 */
  items: TabBarItem[];
  /** 切换回调 */
  onChange: (key: string) => void;
}

interface TabBarItem {
  key: string;
  name: string;
  icon: string;       // 默认状态图标
  activeIcon: string;  // 激活状态图标
}
```

### 两种模式对比

| 特性 | 悬浮模式 (`float`) | 平铺模式 (`flat`) |
|------|---|---|
| 位置 | 悬浮于内容底部 | 固定在页面底部 |
| 间距 | 距底部 16px + 安全区 | 无间距 |
| 圆角 | 左右圆角 24px | 无圆角 |
| 内容影响 | 不占据页面流，覆盖在内容上方 | 需预留底部空间 |
| 效果 | 毛玻璃 + 阴影 | 毛玻璃 |

### 使用示例

```tsx
import { TAB_BAR_ITEMS } from '../../constants';

<AppTabBar
  mode={tabBarMode}
  activeKey={activeTabBarKey}
  items={TAB_BAR_ITEMS}
  onChange={key => {
    setActiveTabBarKey(key);
    history.push(key === 'home' ? '/' : `/${key}`);
  }}
/>
```

## 五、AppModal 底部弹起弹窗组件

### 功能描述

- 底部向上弹起动画（`translateY(100%) → translateY(0)`）
- 蒙层点击关闭 + 手势下滑关闭（下滑超过 100px 触发）
- 支持多种内容类型：`html` / `text` / `image` / `markdown`

### Props

```typescript
interface AppModalProps {
  /** 是否可见 */
  visible: boolean;
  /** 弹窗标题 */
  title?: string;
  /** 弹窗内容 */
  content?: ReactNode;
  /** 内容类型 */
  contentType?: 'html' | 'text' | 'image' | 'markdown';
  /** 内容滑动方向 */
  swipeDirection?: 'horizontal' | 'vertical';
  /** 是否显示关闭按钮，默认 true */
  showClose?: boolean;
  /** 确认按钮文字，默认「确认」 */
  confirmText?: string;
  /** 取消按钮文字，默认「取消」 */
  cancelText?: string;
  /** 点击蒙层关闭，默认 true */
  maskClosable?: boolean;
  /** 关闭回调 */
  onClose?: () => void;
  /** 确认回调 */
  onConfirm?: () => void;
  /** 取消回调 */
  onCancel?: () => void;
}
```

### 使用示例

**确认弹窗（退出登录）：**

```tsx
<AppModal
  visible={logoutModalVisible}
  title="退出登录"
  content={<p>确定要退出登录吗？</p>}
  onConfirm={handleLogout}
  onCancel={() => setLogoutModalVisible(false)}
  onClose={() => setLogoutModalVisible(false)}
/>
```

## 六、KeepAlive 页面缓存

### 功能描述

一级页面切换时保持滚动位置和 UI 状态，避免重新挂载导致的数据丢失和体验不佳。

### 工作原理

- `KeepAlive` 组件维护一个缓存 Map，key 为路由 pathname
- `CacheRoute` 在 Layout 中包裹 `children`，根据当前路由判断是否使用缓存
- 缓存路由列表在 `CACHE_ROUTES` 常量中配置（默认包含 5 个一级页面路由）

### 在 Layout 中的集成

```tsx
// layouts/index.tsx
import CacheRoute from '../components/KeepAlive/CacheRoute';

export default ({ children, location, ...restProps }) => (
  <SharedLayout location={location} {...restProps}>
    <CacheRoute pathname={location.pathname}>
      {children}
    </CacheRoute>
  </SharedLayout>
);
```

### 相关 Hook

- `useKeepAlive()` — 获取 KeepAlive 上下文
- `useKeepAliveActivation()` — 监听页面激活/停用事件

## 七、useSwipe 滑动手势 Hook

### 功能描述

通用左右滑动手势识别，用于 Tab 页面和 Banner 的滑动切换。

### API

```typescript
function useSwipe(options?: UseSwipeOptions): {
  onTouchStart: (e: React.TouchEvent) => void;
  onTouchMove: (e: React.TouchEvent) => void;
  onTouchEnd: (e: React.TouchEvent) => void;
};

interface UseSwipeOptions {
  /** 触发切换的最小水平距离（px），默认 50 */
  threshold?: number;
  /** 触发切换的最小速度（px/ms），默认 0.3 */
  velocityThreshold?: number;
  /** 方向锁定角度 tan 值，默认 0.577（约 30°） */
  directionLockRatio?: number;
  /** 向左滑动回调 */
  onSwipeLeft?: () => void;
  /** 向右滑动回调 */
  onSwipeRight?: () => void;
  /** 实时偏移回调（用于跟手动画） */
  onSwiping?: (offsetX: number) => void;
  /** 滑动结束回调 */
  onSwipeEnd?: () => void;
}
```

### 使用示例

```tsx
const swipeHandlers = useSwipe({
  threshold: 50,
  velocityThreshold: 0.3,
  onSwiping: (offsetX) => setSwipeOffset(offsetX),
  onSwipeLeft: () => handleTabChange(activeIndex + 1),
  onSwipeRight: () => handleTabChange(activeIndex - 1),
  onSwipeEnd: () => setSwipeOffset(0),
});

<main {...swipeHandlers}>
  {/* 内容 */}
</main>
```

### 特性

- **方向锁定**：首次移动超过 5px 时判定方向，30° 内锁定为水平
- **双重判定**：距离阈值 (50px) + 速度阈值 (0.3px/ms)
- **跟手动画**：通过 `onSwiping` 实时获取偏移量
- **边界阻尼**：到达首尾 Tab 时建议将偏移乘以 0.3 减弱
