## 一、整体架构概述

### 1.1 项目定位

本项目为 H5 多页面微应用，是 `super-tools-web` Monorepo 架构中的 H5 子项目，采用组件化设计思路，核心布局由**头部导航**、**Tab 切换模块**、**主体内容区**、**底部导航栏**四层结构组成。各模块均封装为可配置组件，支持跨页面复用。

### 1.2 架构层级


### 1.3 技术选型依据

| 维度 | 技术方案 | 选型理由 |
|------|---------|---------|
| 框架 | React 16 + UmiJS 3 | 与 Monorepo 现有架构对齐，开箱即用路由/构建/Mock |
| 状态管理 | Zustand + immer | 替代已停维护的 DVA，轻量无样板代码，async/await 原生支持 |
| 样式方案 | Less + CSS Variables | 全局变量统一管理设计 token，postcss-pxtorem 自动 rem 转换 |
| 路由 | UmiJS 配置式路由 | 显式声明路由树，支持路由级代码分割 dynamicImport |
| 构建 | Webpack（UmiJS 内置） | targets Chrome 49+/iOS 10+，hash 文件名，exportStatic |
| H5 适配 | postcss-pxtorem (rootValue=20) | 750px 设计稿直接写 px，构建时自动转换 |
| JSBridge | AppSdk（shared 层） | 统一封装 Native 调用，环境检测，参数缓存 |

## 三、公共组件规范

### 3.1 头部导航组件 `<AppHeader />`

#### 视觉规范
- 整体采用**毛玻璃效果**（`backdrop-filter: blur(10px)` + 半透明白色背景）
- 固定在页面顶部，高度 `88px`（CSS 变量 `--header-height`）
- 布局：**标题居左（加粗）+ 按钮组居右**

#### 组件 Props 设计

```typescript
interface AppHeaderProps {
  title: string;                    // 页面标题
  buttons?: HeaderButtonConfig[];   // 按钮配置列表
  showBack?: boolean;               // 是否显示返回按钮（二级页面使用）
  onBack?: () => void;              // 返回按钮回调
}

interface HeaderButtonConfig {
  type: 'search' | 'agent' | 'settings' | 'sort' | 'add' | 'scan' | 'placeholder';
  visible?: boolean | (() => boolean); // 支持静态值或动态函数控制显隐
  onClick?: () => void;
}
```

#### 按钮说明

| 按钮类型 | 图标样式 | 交互行为 |
|---|---|---|
| `search` 搜索 | 搜索图标 + 圆环背景蒙层 | 主体内容区搜索框滚动不可见后才显示；点击跳转搜索页 |
| `agent` 智能体 | 占位图标（待定） | 点击唤起智能体（当前预留，接口待接入） |
| `settings` 设置 | 设置图标 | 点击后在按钮正下方弹出设置选项面板（Popover 形式） |
| `sort` 排序 | 排序图标 | 点击弹出排序选项（最多使用 / 最多收藏 / 最新投稿） |
| `add` 添加收藏 | 加号图标 | 点击跳转首页 |
| `scan` 扫码 | 扫码图标 | 点击唤起扫码功能（调用 AppSdk） |

> **说明：** 按钮渲染顺序与 `buttons` 数组顺序一致，开发时可通过调整数组顺序控制按钮排列。

#### 一级/二级页面差异

| 页面级别 | showBack | 标题位置 | 右侧按钮 |
|---------|----------|---------|---------|
| 一级页面 | `false` | 居左 | 业务按钮组 |
| 二级页面 | `true` | 返回图标后居左 | 可选配置 |

### 3.2 Tab 切换组件 `<AppTabs />`

#### 使用位置
紧贴头部导航下方，高度 `80px`（CSS 变量 `--tabs-height`），主体内容区需动态计算并排除头部导航 + Tab 栏的总高度。

#### 两种模式

**模式A：双 Tab 模式（`double`）**

- 适用场景：仅有 2 个 Tab 时（如特色页的「特色功能 / 会员专属」）
- 样式：两个 Tab 等宽平铺，视觉上与头部导航融为一体（共享毛玻璃背景）
- 切换动画：Active 指示块整体 `translateX` 平移，背景色与字体颜色随 `transition` 同步过渡（非跳变）
- 页面内容切换：左右滑动切换

**模式B：多 Tab 模式（`multiple`）**

- 适用场景：Tab 数量 ≥ 3（如网站页的分类 Tab）
- 样式规范：
  - Tab 元素内容：**图标 + 名称**，圆润胶囊样式（`border-radius: 999px`）
  - Tab 间距：`8px`
  - Active 状态：背景色跟随全局主题色填充
  - 超出屏幕宽度时，Tab 栏支持**左右横向滚动**（`overflow-x: auto`，隐藏滚动条）
  - 切换时，当前 Active Tab **自动滚动居中**（`scrollTo smooth`）
- 页面内容切换：左右滑动切换

#### 组件 Props 设计

```typescript
interface AppTabsProps {
  mode: 'double' | 'multiple';
  tabs: TabItem[];
  activeIndex: number;
  onChange: (index: number) => void;
}

interface TabItem {
  key: string;
  name: string;
  icon?: string; // 图标 URL 或 icon name（多 Tab 模式使用）
}
```

### 3.3 底部导航栏组件 `<AppTabBar />`

#### 两种展示模式（可在设置页切换）

| 模式 | Key | 样式描述 |
|---|---|---|
| **悬浮模式**（默认） | `float` | 悬浮于主体内容底部，距底部 `16px` + 安全区，左右两端圆角 `24px`，毛玻璃效果 + 阴影，不占据页面流式布局 |
| **平铺模式** | `flat` | 固定在页面底部，无圆角，保留毛玻璃效果，占据底部安全区（`padding-bottom: env(safe-area-inset-bottom)`） |

#### 导航项配置

| Key | 名称 | 对应一级页面 | 路由路径 |
|---|---|---|---|
| `home` | 首页 | 首页 | `/` |
| `favorites` | 收藏 | 收藏页 | `/favorites` |
| `featured` | 特色 | 特色页 | `/featured` |
| `sites` | 网站 | 网站页 | `/sites` |
| `mine` | 我的 | 我的页 | `/mine` |

#### 样式规范
- 每个 NavItem 布局：**上图标 + 下名称**
- 图标尺寸：`44px × 44px`
- Active 状态：图标 `scale(1.1)` 弹性放大，颜色跟随主题色（`--primary-color`）

#### 组件 Props 设计

```typescript
interface AppTabBarProps {
  mode: 'float' | 'flat';
  activeKey: string;
  items: TabBarItem[];
  onChange: (key: string) => void;
}

interface TabBarItem {
  key: string;
  name: string;
  icon: string;       // 默认状态图标
  activeIcon: string;  // 激活状态图标
}
```

## 四、路由与状态管理方案

### 4.1 路由设计

#### 路由模式
- **配置式路由（SPA）**：在 `.umirc.dev.ts` / `.umirc.preview.ts` / `.umirc.prod.ts` 中显式声明路由树
- **路由级代码分割**：`dynamicImport` 开启，每个路由独立 chunk
- **静态导出**：`exportStatic: {}` 开启，每个路由生成独立 `index.html`

#### 完整路由树

```typescript
routes: [
  {
    exact: false,
    path: '/',
    component: '@/layouts',     // 公共 Layout 守卫层
    routes: [
      // ========== 一级页面（含底部导航栏）==========
      { path: '/',           component: '@/pages/home',      title: '首页' },
      { path: '/favorites',  component: '@/pages/favorites', title: '收藏' },
      { path: '/featured',   component: '@/pages/featured',  title: '特色' },
      { path: '/sites',      component: '@/pages/sites',     title: '网站' },
      { path: '/mine',       component: '@/pages/mine',      title: '我的' },

      // ========== 二级页面（无底部导航栏）==========
      { path: '/search',     component: '@/pages/search',    title: '搜索' },
      { path: '/login',      component: '@/pages/login',     title: '登录' },
      { path: '/settings',   component: '@/pages/settings',  title: '设置' },
      { path: '/profile',    component: '@/pages/profile',   title: '个人信息' },
      { path: '/member',     component: '@/pages/member',    title: '会员' },
      { path: '/help',       component: '@/pages/help',      title: '使用帮助' },
      { path: '/about',      component: '@/pages/about',     title: '关于我们' },
    ],
  },
]
```

#### 路由 URL 规则

| 环境 | URL 格式 | 示例 |
|------|---------|------|
| 开发 | `http://localhost:8000/fe/h5/micro-tools/{path}` | `/fe/h5/micro-tools/favorites` |
| 预发布 | `https://test.xxx.com/fepreview/h5/micro-tools/{path}` | `/fepreview/h5/micro-tools/settings` |
| 生产 | `https://xxx.com/fe/h5/micro-tools/{path}` | `/fe/h5/micro-tools/mine` |

#### 路由守卫层

```
/ 根路由 → @/layouts 公共守卫层
   ├── 设置页面标题（document.title）
   ├── 登录态检测（Milo / AppSdk）
   ├── vconsole 注入（非生产环境）
   └── 端外跳转引导下载
```

### 4.2 状态管理方案

采用 **Zustand + immer** 中间件，按业务模块拆分 Store：

#### Store 架构图

```
store/
├── global.ts      → 全局设置状态（主题色、导航模式、列表模式）
│                     → localStorage 持久化
│                     → CSS 变量实时同步
├── home.ts        → 首页业务数据（Banner、工具分类列表）
├── favorites.ts   → 收藏业务数据（收藏列表、增删操作）
├── sites.ts       → 网站业务数据（分类 Tab、网站列表、排序）
└── user.ts        → 用户状态（登录态、用户信息、会员状态）
```

#### 全局设置 Store（global.ts）详细字段

```typescript
interface GlobalState {
  tabBarMode: 'float' | 'flat';           // 底部导航栏模式
  toolListMode: 'grid' | 'card' | 'flow' | 'single' | 'double'; // 工具列表模式
  favListMode: 'single' | 'double';       // 收藏列表模式
  themeColor: string;                      // 主题色（HEX）
  sortType: 'most_used' | 'most_fav' | 'newest'; // 排序方式
  activeTabBarKey: string;                 // 当前底部导航激活项
  isSearchBoxVisible: boolean;             // 首页搜索框可见状态
}
```

#### 持久化策略

| 字段 | 是否持久化 | 存储方式 |
|------|----------|---------|
| tabBarMode | ✅ | localStorage |
| toolListMode | ✅ | localStorage |
| favListMode | ✅ | localStorage |
| themeColor | ✅ | localStorage + CSS 变量同步 |
| sortType | ❌ | 运行时 |
| activeTabBarKey | ❌ | 运行时 |
| isSearchBoxVisible | ❌ | 运行时（IntersectionObserver 驱动） |

### 5.3 核心数据模型

```typescript
/** Banner 广告位 */
interface BannerItem {
  id: string;
  imageUrl: string;
  linkUrl: string;
  title: string;
}

/** 工具项 */
interface ToolItem {
  id: string;
  name: string;
  icon: string;
  subtitle?: string;
```

## 十、关键交互逻辑汇总

```
1. 搜索框可见性检测
   └── 首页主体内容区搜索框进入/离开视口
       ├── 进入视口 → 头部导航 search 按钮隐藏
       └── 离开视口 → 头部导航 search 按钮显示
       └── 实现方式：IntersectionObserver → setSearchBoxVisible(boolean)

2. Tab / NavBar 切换动画
   └── Active 指示块平移动画（非跳变）
       └── 背景色 + 字体颜色同步跟随主题色过渡
       └── 实现方式：CSS transform + transition

3. 多 Tab 自动居中
   └── 点击 Tab 后，该 Tab 自动滚动至 Tab 栏水平居中位置
   └── 实现方式：scrollTo({ left, behavior: 'smooth' })

4. 底部导航栏高度适配
   └── 悬浮模式：主体内容区不需预留底部空间，导航栏覆盖在内容上方
   └── 平铺模式：主体内容区底部需预留导航栏高度 + 安全区高度

5. 页面高度计算
   └── 主体内容区高度 = 100vh - HeaderHeight - TabsHeight(若有) - TabBarHeight(平铺模式下)
       建议使用 CSS 变量统一管理各模块高度

6. 主题色实时同步
   └── 设置页修改主题色
       ├── 更新 Zustand Store
       ├── 同步更新 CSS 变量：document.documentElement.style.setProperty('--primary-color', color)
       └── 持久化到 localStorage

7. 弹窗手势下滑关闭
   └── AppModal 内容区触摸事件
       ├── touchstart → 记录 startY
       └── touchend → 计算下滑距离 > 100px → 触发关闭

8. 路由切换时底部导航同步
   └── 一级页面切换 → 更新 activeTabBarKey
   └── 二级页面 → 不显示底部导航栏
```

## 十二、技术建议与注意事项

| 方向 | 建议 |
|---|---|
| 组件框架 | React 16 + UmiJS 3 + Zustand + TypeScript |
| 路由管理 | React Router（UmiJS 内置），配置式路由 |
| 状态管理 | Zustand + immer 管理全局设置 + 页面数据 |
| 动画实现 | CSS Transition + Transform 实现平移动画，避免使用 JS 逐帧计算 |
| 毛玻璃效果 | `backdrop-filter: blur(10px)` + 半透明背景色 |
| 高度计算 | 使用 CSS 变量 `--header-height`、`--tabs-height`、`--tabbar-height` 统一管理 |
| 滚动检测 | 使用 `IntersectionObserver` 检测搜索框可见性 |
| iframe 安全 | 外链页面需处理跨域及 `X-Frame-Options` 限制，建议后端代理 |
| H5 适配 | 750px 设计稿，postcss-pxtorem rootValue=20，直接写 px |
| 公共层引用 | 通过 `@/utils`、`@/hooks` 等别名引用 shared 层 |
| Mock 数据 | 开发环境使用 `mock/index.ts`，所有接口均有 Mock 覆盖 |
| 性能优化 | 路由级代码分割（dynamicImport）、图片懒加载、组件按需渲染 |
| 安全区适配 | 使用 `env(safe-area-inset-bottom)` 处理 iPhone 底部安全区 |
